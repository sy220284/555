# 现代红色警戒（工作名）

一款把经典基地建设即时战略推进到 2037 年现代/近未来战争的项目：基地、资源、爆兵、阵营差异和超级武器仍然是核心，但战争体系扩展到无人系统、机器人、AI 战斗指挥、电子战、综合防空、远程火力、海空联合作战与有限轨道支援。

> 当前仓库以“完整可执行设计与技术规格”为主。若未取得相关商业 IP 授权，所有专有名称、角色、音乐、美术与品牌必须替换为原创内容。

## 核心体验

1. **经典即时战略爽感**：建设、采集、生产、科技、爆兵、决战。
2. **现代战争体系感**：侦察—识别—压制—打击—突破—占领—保障。
3. **AI 统帅感**：玩家负责战略意图，AI 接管被授权的局部战术、战斗群和战区执行。
4. **未来升级感**：机械化 → 信息化 → 无人化 → 机器人化 → 智能化 → 空天化 → 红警式未来科技。

## 首发设计边界

- 4 套基础战争体系。
- 15 个国家进入世界设定，10 个首发竞技选择。
- 5 级科技。
- 完整陆战、空战；核心海战；有限轨道支援。
- 无人、机器人、AI 指挥、电子战、简化后勤、战争迷雾与情报系统。
- 24 个主线任务、16 张多人地图、5 种多人玩法。
- 标准 1v1 300—800 活动单位；大型团队 1000—3000；更高规模只作为战略模式与压力测试目标。

## 开发原则

- 复杂度藏在系统里，玩家只面对清晰决策。
- AI 负责执行，玩家保留战略、资源、科技和高价值能力决策权。
- 机器人同时受工业资源、战略资源、电力、指挥容量和算力限制。
- 远程火力用于塑造战场，最终胜利仍依赖实体部队控制区域。
- 太空是战略支援层，不做第二套太空即时战略。
- 所有强力系统必须存在成本、弱点与反制。
- 数据驱动，禁止把国家、单位和数值大量硬编码进逻辑。
- 确定性、性能、网络同步、平衡与自动测试从第一天进入门禁。
