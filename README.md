# 现代红色警戒（工作名）

一款把经典基地建设即时战略推进到2037年现代/近未来战争的项目：基地、资源、生产、科技、阵营差异和超级武器仍是核心，同时扩展无人系统、机器人、AI战斗指挥、电子战、综合防空、远程火力、海空联合作战与有限轨道支援。

> 若未取得相关商业IP授权，所有受保护专有名称、角色、音乐、美术与品牌必须在发行前替换为原创内容。项目逻辑ID与显示层分离，支持整体替换。

## 核心体验

1. **经典即时战略爽感**：建设、采集、生产、科技、爆兵、决战。
2. **现代战争体系感**：侦察—识别—压制—打击—突破—占领—保障。
3. **AI统帅感**：玩家负责战略意图，AI接管被授权的局部战术、战斗群和战区执行。
4. **未来升级感**：机械化 → 信息化 → 无人化 → 机器人化 → 智能化 → 空天化 → 红警式未来科技。

## 冻结设计边界

- 4套基础战争体系。
- 15个国家进入世界设定，10个首发竞技选择。
- 5级科技，T4后高级科技分叉。
- 完整陆战、空战；核心海战；有限轨道战略支援。
- 无人、机器人、AI指挥、电子战、网络战、简化后勤、战争迷雾与情报系统。
- 24个主线任务、16张多人地图、5种多人玩法。
- 最低完整体验直接锚定2026主流游戏电脑：6核12线程级CPU、16GB、8GB级显存、NVMe SSD，1080P标准画质。
- 标准现代模式目标800—1500有效活动实体；大型团队1500—3000；战区模式扩展3000—5000。

## 开发原则

- 复杂度藏在系统里，玩家只面对清晰决策。
- AI负责执行，玩家保留战略、资源、科技和高价值能力决策权。
- 机器人同时受工业/战略资源、电力、指挥容量和算力限制。
- 远程火力用于塑造战场，最终胜利仍依赖实体部队控制区域。
- 太空是战略支援层，不做第二套太空即时战略。
- 所有强力系统必须存在成本、弱点与反制。
- 数据驱动，稳定ID贯穿设计、代码、地图、任务、资源、音频和测试。
- 确定性/可复现、性能、网络同步、平衡、安全和自动测试从第一天进入门禁。
- 性能优先从架构、算法、数据布局、批处理和资产预算解决，不能把成本转嫁给玩家硬件或正常画质。
