# 母设计文档

## 产品愿景

2037年现代/近未来即时战略。玩家从直接控制步兵、坦克和火炮，逐步成长到管理战斗群、AI侧翼、无人/机器人部队、空海支援和有限轨道资源，但始终由玩家决定战略方向、战争节奏和结束方式。

项目的核心体验必须始终按以下顺序成立：

1. **现代红警式即时战略**：建设、扩张、爆兵、克制、机动、地图争夺和高反馈战斗；
2. **现代体系战争**：情报、电子战、战略设施、后勤、海陆空协同改变战争方式；
3. **AI统帅成长**：规模越大，玩家越从单位操作者成长为战斗群和战区指挥者；
4. **高阶扩展系统**：机器人、网络战、轨道、T5未来科技和大型战区用于增加纵深，不能反过来压垮前三层。

任何高级系统都不得以牺牲基础RTS爽感、可读性和直接控制能力为代价。

## 核心循环

建设与资源 → 侦察与地图争夺 → 建立信息链 → 电子/无人接触 → 远程火力塑形 → 陆海空突破 → 占领关键区域 → 前移保障 → 科技分叉 → 形成终局能力。

该循环不是时间脚本。玩家可以快攻、慢推、跳科技、长期停留低科技、海空封锁、后勤切断、龟缩反击或多线推进，只要资源、工业、指挥和后勤允许。

## 局部战斗体验红线

宏观系统只有能转化为玩家可感知的局部战斗选择才算成立。标准交战必须支持以下可读节拍：

`发现 → 识别 → 接敌 → 第一轮火力 → 反制 → 机动/压制 → 突破或脱离 → 追击/巩固`

玩家必须能从画面、音频、状态提示和单位行为理解“为什么打赢/打输”，不得只表现为两个数值池互相扣减。

详细规则见 `03B_COMBAT_PACING_FEEDBACK.md`。

## 玩家始终要做的决策

- 资源投向经济、军力还是科技；
- 主攻/防守方向；
- 何时升级、选择哪条T4/T5分支；
- 哪条战线交给AI、预算和交战规则；
- 哪些战略目标值得使用高价值火力；
- 是否继续推进、巩固、绕行、围困或转入其他战线；
- 何时发动终局能力。

## AI统帅原则

AI是核心玩法，不是自动代打。标准授权语言统一为六个维度：

`目标 + 区域 + 姿态 + 风险 + 禁令 + 预算`

玩家可以只给简单命令，系统使用安全默认值补全；高阶玩家可进一步限制追击距离、最大可接受损失、是否调用预备队、是否跨越当前前线、是否进入城区、补给撤回阈值等。

AI必须说明关键行为原因，例如因战力比不足撤退、因补给不足转入整补、因情报等级不足拒绝精确打击。玩家直接命令永远覆盖AI旧计划。

## 自由战争原则

1. 不用比赛时长推动玩家。
2. 不因经过多少分钟改变资源、伤害、积分倍率或科技权限。
3. 不设固定“前期/中期/后期”时间门槛。
4. 节奏由资源、工业、地图控制、情报、后勤、交通、兵力和科技投资自然形成。
5. 允许长期防御，只要玩家愿意承担失去外部资源、情报和战略空间的自然代价。
6. 允许快速决战，也允许长时间大战。
7. 技术性时间仍可存在：建造、研究、武器冷却、占领作业、重连、动画和服务超时，但这些时间不能作为强迫战争升级的节奏器。

详细规则见 `03A_FREEDOM_WARFARE.md`。

## 模式母规则

五种模式共享同一战争内核。**征服 + 标准现代规则是多人主平衡基准和母玩法**。

其他模式只允许通过以下维度派生：

- 开局军力与建设状态；
- 启用的系统深度；
- 地图和战略设施布局；
- 胜负条件；
- 初始资源与科技；
- AI可用权限。

禁止为五种模式分别维护互相冲突的战斗、情报、经济或单位规则。模式特有偏离必须显式记录在对应规则集。

## 规则深度预设

规则深度和游戏模式是两个不同维度：前者决定启用多少系统，后者决定战争目标与开局状态。界面中禁止再把规则深度称为“经典模式/现代模式/战区模式”，避免与五种游戏模式混淆。

### 简化规则

自动化后勤，关闭复杂轨道、深层电子战和高级战区AI；突出基地、陆空、无人和超级武器。用于教学、自定义房和偏传统即时战略体验。

### 标准现代规则（主平衡基准）

启用机器人、AI指挥、电子战、简化后勤、有限轨道和现代情报。标准排位默认使用该深度，除战区战争另有规定。

### 完整战争规则

启用大地图、海军、多战线、完整后勤、战区AI和更多轨道支援。主要用于战区战争、合作和大型自定义对局。

规则深度只控制系统启用范围，不决定比赛必须打多久，也不改变同一模式的基础胜负逻辑。机器可读规则集通过 `depth_profile` 取值 `SIMPLIFIED / MODERN_STANDARD / FULL_WAR`。

## 五级科技

- T1现代机械化：基础步兵、坦克、炮兵、基础无人、防空。
- T2信息化：数据链、电子战、精确火力、预警、高级无人。
- T3无人/机器人：AI指挥中心、机器人、无人战车、巡飞武器、无人僚机。
- T4智能化：高级AI、机器人战斗群、定向能、高速远程武器。
- T5未来化：机器军团、轨道对抗、光棱/磁暴/铁幕式未来能力、认知战。

T4起要求科技分叉，标准对局不能把所有高级方向点满。科技层级只受资源、建筑、前置和玩家投资决定，不按比赛时间解锁。征服标准规则允许部分T3/T4/T5科技额外绑定战略材料访问，但基础生存与T1/T2不得被矿产锁死。

## 战略设施原则

机场、港口、雷达、数据中心、能源、物流、卫星站、桥梁和通信节点必须形成真实战争价值。每类关键设施至少具备：

`正常收益 → 受损降级 → 失效后果 → 可恢复路径`

设施被摧毁应削弱对应体系，不允许单点导致全军硬停机。设施价值必须足够高到值得玩家改变主攻方向，但不能高到形成唯一必抢点。

## 平衡评价原则

单位和建筑不能只按伤害与造价评价。内部平衡至少同时考虑：

`综合价值 = 直接战斗价值 + 信息价值 + 体系贡献 + 战略投射 + 生存/机动价值 - 工业/战略资源成本 - 指挥成本 - 算力成本 - 后勤成本 - 操作负担`

该公式是分析框架，不要求玩家看到单一总分。预警、电子战、雷达、AI、物流等低直接伤害对象必须按体系贡献评估，避免“伤害低但组合超模”长期逃逸平衡检测。

## 系统复杂度红线

所有新增或重大扩展系统必须同时评估六项预算：玩家操作、界面信息、CPU、网络、AI决策和资产生产。规则见 `../specs/SYSTEM_COMPLEXITY_BUDGET.md`。

原则：每增加一个需要玩家频繁管理的系统，必须同步自动化或删除等量低价值操作；不能靠“AI以后会帮忙”掩盖本身不可读的设计。

## 取舍红线

- 远程火力不得取代占领与地面推进。
- 太空不做第二套RTS。
- AI不得替玩家决定大战略。
- 后勤保持三态，不细分现实弹药型号。
- 国家现实军力不直接映射数值强弱。
- 机器人不能淘汰全部人类部队。
- 强力能力必须有成本、物理节点和反制。
- 禁止通过固定比赛时长、强制阶段、倒计时增益或超时惩罚推动战局。
- 禁止新增常驻资源条来承载可以通过状态/标签表达的复杂度。
- 在基础RTS、战斗反馈、AI统帅和战略设施尚未形成完整可玩闭环前，禁止继续横向增加新的大型玩法层。

## 内容基线与生产顺序

最终内容目标保持：

- 4基础体系；15国世界设定；10首发竞技选择。
- 24关主线，16张首发多人图。
- 5种多人玩法：歼灭、征服、前线、战区战争、快速战争。
- 不设标准对局时长目标。统计时长只用于观察健康度、服务器容量和玩家偏好，不作为规则触发条件。

生产必须分阶段：

1. **第一可玩闭环**：`MAP_GRAY_RANGE` + 基础陆战 + 经济 + 战斗 + 情报 + AI + 战略设施；
2. **核心可玩集**：四体系共同规则完成，优先6国达到同一质量门禁；
3. **竞技集**：扩到10国和核心排位地图；
4. **完整内容集**：其余国家、海军、轨道、T5和大型战区在基础闭环稳定后扩展。

不得用“已有15国/16图设计”倒逼同时生产全部正式资产。

## 成功判断

关闭轨道和复杂后勤后仍然必须是一款好玩的即时战略；加入无人、机器人和AI后，玩家感受应是“决策更丰富、操作更轻”。同一张图应该允许快攻、稳推、围困、侧翼、海空封锁和长期消耗产生不同但合法的战争过程。

第一阶段成功的最小判断不是文档数量，而是：玩家能够在 `MAP_GRAY_RANGE` 从建设开始，通过侦察、交战、AI授权、战略设施争夺和战争能力崩溃，完成一局有明确胜负原因且愿意再玩一次的对局。

设计完成不等于项目完成。任何核心规则只有同时进入机器可读数据、代码契约和自动测试，才算真正进入实现主线。
