# 母设计文档

## 产品愿景

2037年现代/近未来即时战略。玩家从直接控制步兵、坦克和火炮，逐步成长到管理战斗群、AI侧翼、无人/机器人部队、空海支援和有限轨道资源，但始终由玩家决定战略方向、战争节奏和结束方式。

## 核心循环

建设与资源 → 侦察与地图争夺 → 建立信息链 → 电子/无人接触 → 远程火力塑形 → 陆海空突破 → 占领关键区域 → 前移保障 → 科技分叉 → 形成终局能力。

该循环不是时间脚本。玩家可以快攻、慢推、跳科技、长期停留低科技、海空封锁、后勤切断、龟缩反击或多线推进，只要资源、工业、指挥和后勤允许。

## 玩家始终要做的决策

- 资源投向经济、军力还是科技；
- 主攻/防守方向；
- 何时升级、选择哪条T4/T5分支；
- 哪条战线交给AI、预算和交战规则；
- 哪些战略目标值得使用高价值火力；
- 是否继续推进、巩固、绕行、围困或转入其他战线；
- 何时发动终局能力。

## 自由战争原则

1. 不用比赛时长推动玩家。
2. 不因经过多少分钟改变资源、伤害、积分倍率或科技权限。
3. 不设固定“前期/中期/后期”时间门槛。
4. 节奏由资源、工业、地图控制、情报、后勤、交通、兵力和科技投资自然形成。
5. 允许长期防御，只要玩家愿意承担失去外部资源、情报和战略空间的自然代价。
6. 允许快速决战，也允许长时间大战。
7. 技术性时间仍可存在：建造、研究、武器冷却、占领作业、重连、动画和服务超时，但这些时间不能作为强迫战争升级的节奏器。

详细规则见 `04_FREEDOM_WARFARE.md`。

## 三种复杂度

### 经典模式
自动化后勤、轨道、高级电子战和高级AI；突出基地、陆空、无人和超级武器。

### 现代模式（主平衡基准）
启用机器人、AI指挥、电子战、简化后勤、有限轨道和现代情报。

### 战区模式
启用大地图、海军、多战线、完整后勤、战区AI和更多轨道支援。

三种复杂度控制系统深度，不决定比赛必须打多久。

## 五级科技

- T1现代机械化：基础步兵、坦克、炮兵、基础无人、防空。
- T2信息化：数据链、电子战、精确火力、预警、高级无人。
- T3无人/机器人：AI指挥中心、机器人、无人战车、巡飞武器、无人僚机。
- T4智能化：高级AI、机器人战斗群、定向能、高速远程武器。
- T5未来化：机器军团、轨道对抗、光棱/磁暴/铁幕式未来能力、认知战。

T4起要求科技分叉，标准对局不能把所有高级方向点满。科技层级只受资源、建筑、前置和玩家投资决定，不按比赛时间解锁。

## 取舍红线

- 远程火力不得取代占领与地面推进。
- 太空不做第二套RTS。
- AI不得替玩家决定大战略。
- 后勤保持三态，不细分现实弹药型号。
- 国家现实军力不直接映射数值强弱。
- 机器人不能淘汰全部人类部队。
- 强力能力必须有成本、物理节点和反制。
- 禁止通过固定比赛时长、强制阶段、倒计时增益或超时惩罚推动战局。

## 内容基线

- 4基础体系；15国世界设定；10首发竞技选择。
- 24关主线，16张首发多人图。
- 5种多人玩法：歼灭、征服、前线、战区战争、快速战争。
- 不设标准对局时长目标。统计时长只用于观察健康度、服务器容量和玩家偏好，不作为规则触发条件。

## 成功判断

关闭轨道和复杂后勤后仍然必须是一款好玩的即时战略；加入无人、机器人和AI后，玩家感受应是“决策更丰富、操作更轻”。同一张图应该允许快攻、稳推、围困、侧翼、海空封锁和长期消耗产生不同但合法的战争过程。
