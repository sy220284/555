# 阵营与国家特色

## 四大基础体系

### 联合防卫体系
定位：全球感知、航空、隐身、精确火力、高质量 AI。强在先发现先打；弱在昂贵和体系节点依赖。

### 中国体系
定位：战区控制、远程拒止、防空反导、大规模无人/机器人、工业与舰队。强在区域体系完整性；弱在前期投入和感知链损伤后的远程效率。

### 欧亚体系
定位：火力密度、电子战、低成本无人、重防空、重装甲、维修和工业动员。强在持续消耗；弱在全球信息融合和高端远洋持续性。

### 尤里体系
定位：认知战、AI 污染、机器军团、假目标与神经网络。强在打乱体系；弱在算力、能源、中央节点和正面工业规模。

## 国家特色规则

国家 = 基础体系 + 被动 + 2—4 个独占单位/模块 + 特色建筑/科技 + 战略能力。禁止复制整套科技树。

## 15 国定位

- 中国：战区控制。龙骑主战平台、蜂巢无人车、玄武重型机器人、雷霆火力、神盾大型舰；天穹强化区域感知、防空、反导、反舰和火力共享。
- 美国：杀伤链。幽灵制空机、猎鹰无人僚机、阿特拉斯机器人、预警体系；战争云/全球鹰眼强化目标确认与持续跟踪。
- 俄罗斯：持续战争。犀牛、天启、猎犬机器人、柳叶刀蜂群、震荡电子战；战争工业/总动员强化补充与维修。
- 英国：远征。特勤队、未来战机、龙火定向能、攻击潜艇；日不落网络共享海外保障。
- 法国：战略自主。多用途航空、隐身无人机、未来地面平台；全谱作战允许航空任务快速重构。
- 德国：模块化。未来主战平台、模块战车、模块机器人；模块化军团快速更换任务组件。
- 日本：岛链拒止。岛屿机动、神盾舰、电磁炮舰、无人反潜；八咫镜连接岛屿、舰队、防空、航空和卫星。
- 韩国：自动军工与炮兵。未来坦克、自行火炮、激光反无人、自动制造；机器军工城提高持续产能。
- 以色列：防御成本交换。未来坦克、智能步兵、激光/多层反导；大卫之盾自动选择经济拦截手段。
- 印度：战略纵深。高原部队、高速远程打击、大型火箭；三军火网共享陆海空目标。
- 土耳其：无人航空。战术无人机、无人战斗机、无人航空母站；狼群协议自动划分侦察/诱饵/干扰/攻击角色。
- 乌克兰：快速迭代。光纤无人、地面机器人、分布式制造；敌方反复使用同类战术后获得针对性适应；无人防线建立纵深侦察打击区。
- 澳大利亚：海底无人。无人僚机、大型无人潜航器、攻击潜艇、海底传感器；幽灵海域建立隐蔽水下控制区。
- 波兰：陆地堡垒。重装甲、大量炮兵、多层防空、快速工事；东部之盾快速形成纵深防区。
- 伊朗：非对称交换。地下设施、机动远程火力、低成本无人、假目标；千箭网络用诱饵和数量制造防御压力。

首发排位优先：中国、美国、俄罗斯、英国、法国、日本、以色列、土耳其、乌克兰、尤里。其余国家从第一天进入数据和战役体系，达到质量门禁即可开放竞技。
