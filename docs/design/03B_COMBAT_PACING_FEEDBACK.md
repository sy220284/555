# 战斗节拍、手感与反馈

本文件定义555局部战斗的上位体验标准。目标不是把战斗做成复杂军武模拟，而是让现代体系战争在RTS视角下可读、可操作、可反制、可复盘。

## 1. 核心战斗节拍

标准局部交战按以下阶段组织：

`发现 → 识别 → 接敌 → 第一轮火力 → 反制 → 机动/压制 → 突破或脱离 → 追击/巩固`

阶段不是固定时间脚本，也不要求所有交战完整经历全部步骤。它们用于检查玩家是否始终拥有可理解的决策窗口。

## 2. 发现

玩家首先需要知道“有敌情”，但不一定立刻知道敌人完整信息。

主要来源：侦察单位、雷达、友军共享、无人机、预警平台、战区AI报告。

合格反馈：

- 地图出现疑似方向或区域；
- 音频/语音只报告已知事实；
- 未确认目标不得显示精确型号、完整生命和隐藏能力；
- AI不得读取玩家看不到的真实状态。

## 3. 识别

玩家通过继续侦察、多源传感、接近或目标行为把情报从未知提升为疑似、确认、锁定。

情报提升必须带来可感知收益，例如：

- 更可靠的目标类别；
- 更稳定的远程武器命中；
- 更精确的威胁提示；
- 更高质量的AI目标选择。

禁止把情报系统做成后台百分比而没有战斗表现差异。

## 4. 接敌与第一轮火力

第一轮火力必须有明确的先手价值，但不能形成“先看到即必杀”。

玩家应能通过以下方式影响第一次交换：

- 侦察质量；
- 阵型与朝向；
- 掩体和地形；
- 主动防护；
- 电子战；
- 预先部署的防空/反无人；
- 先手远程压制。

重型单位和核心战斗群必须保留足够反应窗口，避免高价值单位在无预警下瞬间消失。

## 5. 反制窗口

任何强体系都必须给对手至少一条现实可执行的反制链。

示例：

- 远程火力强 → 依赖侦察/补给/暴露位置，可被机动、电子战、反炮兵或突击反制；
- 无人蜂群强 → 可被防空、电子战、定向能和廉价反无人系统反制；
- 重装甲强 → 可被穿甲、侧击、机动切断和后勤消耗反制；
- 高级AI强 → 可攻击算力、通信、数据和授权节点；
- 防御阵地强 → 可围困、绕行、断供或通过多域手段拆体系。

反制不能只写在文档里，必须能从界面、单位说明、战场结果中被玩家理解。

## 6. 机动与压制

移动必须是战斗行为的一部分，不是单位之间走到射程后原地对射。

需要支持：

- 侧翼与绕后；
- 主动后撤；
- 掩护撤退；
- 追击限制；
- 火力压制下的转移；
- 预备队投入；
- 战斗群局部重组。

压制、传感退化、机动受损等状态优先改变行为和效率，避免所有非致死效果都等价为“减血”。

## 7. 突破、脱离与巩固

玩家不应被迫把每次接触打到最后一个单位死亡。

战斗群应能：

- 达到目标后停止无意义追击；
- 损失超过风险阈值时脱离；
- 补给不足时主动转入整补；
- 占领区域后巩固并等待保障前移；
- 玩家直接下令时立即改变上述行为。

一场优秀交战可以以敌军撤退、交通被切断、阵地被放弃或战略设施失效结束，而不必全部击毁。

## 8. 玩家决策窗口

局部战斗中的高价值变化必须给玩家合理反应窗口。

需要重点验证：

- 首次受到远程火力时能否定位大致威胁方向；
- 主动防护耗尽是否可观察；
- 防空备弹不足是否可观察；
- 通信/传感下降是否可观察；
- 机器人自主等级下降是否可观察；
- 战斗群准备撤退/整补前是否向玩家报告原因。

不得通过大量弹窗实现这些反馈，优先使用战场图标、状态条、音频和AI摘要。

## 9. 战斗反馈优先级

战斗表现按以下优先级设计：

1. 威胁来源；
2. 命中/拦截/未命中原因；
3. 单位进入严重状态；
4. 战斗群行为改变；
5. 普通伤害数字和装饰性效果。

特效不得遮挡命中结果、危险区域和单位识别。竞技模式可减少烟雾、闪光和震屏，但不能删除规则信息。

## 10. 音频反馈

玩家不看单位面板也应能通过声音区分核心威胁类别：坦克炮、火箭、远程火炮、防空拦截、无人蜂群、激光、电磁武器和战略能力。

战略警报优先级高于普通炮火。同类大规模声音需要聚类，避免声场变成无意义噪声。

## 11. AI在战斗中的职责

AI默认负责低价值操作：

- 队形；
- 基础避障；
- 自动反击；
- 维修/补给回归；
- 已授权范围内的局部目标排序；
- 按姿态决定有限追击、脱离和整补。

AI不得替玩家决定新的大战略目标、主攻方向或高价值战略资源投入。

关键行为改变必须可解释，例如：

- `战力比0.71，低于均衡姿态撤退阈值0.75，开始脱离。`
- `补给不足，停止追击并转入整补。`
- `目标仅为疑似，禁止使用要求锁定的远程武器。`

## 12. 平衡与手感验收

每个主要单位类别和战斗群组合至少验证：

- 是否存在明确战术角色；
- 是否存在玩家可理解的克制；
- 先手是否有价值但非绝对；
- 高价值单位是否存在合理反应窗口；
- 移动、撤退、压制是否真实影响结果；
- 战斗结果是否能从反馈中解释；
- AI接管后是否减少低价值操作而不减少玩家关键决策。

## 13. 第一可玩战斗闭环

`MAP_GRAY_RANGE` 第一阶段只需要证明陆战核心：

`侦察 → 接敌 → 坦克/步战/反装甲/火炮/基础防空组合交战 → 玩家或AI机动 → 撤退/整补 → 再次接敌 → 摧毁战争能力`

在这条链没有达到可玩和可读之前，不以增加更多T5、轨道、海军或国家独占单位作为主要进度。
