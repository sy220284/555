# 核心玩法、模式与节奏

## 对局核心循环

1. 展开基地与初始侦察。
2. 控制工业资源、数据/战略设施和主要交通线。
3. 选择扩张、快攻、科技、海空、远程火力或防御投资。
4. 无人系统、机器人、电子战和AI指挥按玩家科技路线进入战场。
5. 通过情报、火力、机动和后勤逐步改变局部力量对比。
6. 形成突破、围困、封锁、反攻、纵深袭击或体系打击。
7. 通过模式对应的战争状态达成胜利。

以上顺序是典型行为，不是时间脚本。玩家可以跳过、延后或长期停留某一层级。

快速战争是唯一默认跳过“发展准备”环节的标准模式：玩家进入LIVE前已经处于满科技、完整基地体系和足够现役编制状态，从第一分钟直接进入综合战争。

## 节奏原则

游戏不使用“经过多少分钟”强制改变规则。

允许：

- T1/T2长期消耗；
- 高风险快速科技；
- 早期重兵快攻；
- 先海军/空军再地面；
- 防御反击；
- 纵深破袭和后勤封锁；
- 长时间战区对抗。

系统只提供资源、工业、交通、补给、算力、情报和战略设施的真实约束。战争快慢由玩家行为和地图状态决定。

## 模式

### 歼灭
目标是使敌方战争体系失去继续组织生产和指挥的能力。主基地被毁不代表自动结束，只要仍存在合法指挥/生产重建路径，战争就可以继续。

### 征服
围绕战略区域和基础设施建立实际控制。区域价值来自工业、机场、港口、数据中心、能源、交通等真实功能；积分可以作为自定义规则，但不是标准征服的核心。

### 前线
采用动态前线。前线由实际控制区域、兵力存在、补给连接、交通和情报共同形成，不使用固定A→B→C节点链。允许正面突破、侧翼、空降破袭、两栖登陆、包围和绕过。

### 战区战争
完整高自由度战争沙盘。大地图、多战线、完整后勤、海军、L1—L4 AI和轨道支援全部开放。胜负来自战区战争能力崩溃或战略控制，而不是累计到固定分钟/固定积分。

### 快速战争
快速战争是“**满战备直接开战**”。

进入游戏时双方已经完成：

- T1—T5及国家特色科技全部解锁；
- 功能型建筑体系完整部署；
- 电力、算力、补给与指挥体系处于可战状态；
- 陆军、航空、无人/机器人、火力、防空、电子战、工程保障等主要兵种已经形成足够编制；
- 地图支持海军时同时生成海军编队；
- L1—L4 AI和A1—A4自主能力可按玩家授权使用；
- 战略能力所需实体节点已建成，但高价值武器按正常初始充能规则开始。

玩家开局不需要研究科技，也不需要先造一套基地和基础军队。第一件真正重要的事情是：编组、部署、判断敌情和制定作战计划。

快速战争保留正常生产、补损、扩建、资源、后勤、电子战和战略体系。它不会通过缩短生产时间、提高伤害或限定局长来“快速”。

## AI统帅体验

玩家可把“防守东线”“巡逻海域”“保护火力群”等任务交给AI。AI只在授权单位、预算、区域和交战规则内执行；玩家直接下达命令时立即覆盖该编队的AI计划。

默认AI只报告事实和执行任务，不主动推动玩家“现在应该总攻”。战略建议为可选功能，关闭后不影响AI执行能力。

快速战争因为开局已经是完整战争状态，因此允许玩家从开局就使用L1—L4全部AI指挥层级，但权限红线与其他模式完全一致。

## 地图驱动力

地图不能只用矿区驱动争夺。机场、港口、雷达、数据中心、能源、物流、卫星站、桥梁和海底通信节点必须提供真实价值，使离开主基地成为有吸引力的选择，而不是系统强迫。

快速战争地图还必须提供足够大的出生部署区和前沿缓冲，使满编部队可以完成初始编组，而不会在玩家获得控制权前直接进入不可逆交火。

## 胜负与防拖延

不通过倒计时、超时增益、资源衰减或伤害倍率防拖延。

防止无意义拖局依靠战争状态：

- 没有可用指挥/生产重建路径的残余单位不能让失败方永久延续比赛；
- 战略区域和基础设施本身提供实际能力，龟缩方如果放弃地图会自然失去经济、情报、后勤和机动空间；
- 围困、封锁、切断交通和摧毁体系节点都是合法终结方式；
- 超级武器属于玩家投资路线，不承担系统强制结束比赛的职责。
