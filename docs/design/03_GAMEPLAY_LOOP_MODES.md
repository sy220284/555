# 核心玩法、模式与可玩性

## 对局核心循环

现代红警的通用循环仍然是：建设/战备 → 侦察 → 获取资源与战略空间 → 建立信息/保障链 → 形成兵种体系 → 局部交战 → 突破/围困/封锁/反击 → 改变敌我战争能力 → 达成模式胜利。

这不是时间脚本。不同模式从循环中的不同位置开始，玩家可以快攻、慢推、科技冲刺、长期低科技作战、海空封锁、龟缩反击、多线推进或长期消耗。

## 五种模式的核心差异

| 模式 | 战争从哪里开始 | 初始军力 | 玩家主要体验 |
|---|---|---:|---|
| 歼灭 | 战争机器刚开始建立 | 10%—15%有效指挥容量 | 建设、扩张、科技、决战完整循环 |
| 征服 | 基础体系已成型 | 15%—25% | 边发展边争夺有真实功能的战略区域 |
| 前线 | 战线已经存在 | 30%—40% | 突破、包围、预备队、补给和动态前线 |
| 战区战争 | 成熟战区已经运转 | 40%—50% | 多战线、工业、海空、后勤和AI统帅 |
| 快速战争 | 战争机器完全成熟 | 65%—70% | 满科技、满体系、现役编制直接综合作战 |

详细开局、翻盘、地图和AI规则见 `../specs/MODE_PLAYABILITY_PROFILES.md`。

## 自由节奏原则

标准模式不使用“经过多少分钟”强制改变资源、伤害、科技、积分或胜利条件。

系统只提供真实约束：资源、工业、交通、补给、算力、情报、战略设施、兵力损耗和空间控制。战争节奏来自玩家行为和地图状态。

允许：

- 早期重兵快攻；
- 高风险快速科技；
- T1/T2长期消耗；
- 先空军/海军再地面；
- 防御反击；
- 纵深破袭、后勤封锁；
- 长时间战区对抗。

## 歼灭

### 定位

最接近经典红警的完整发展模式。玩家从较小基地和低战备状态开始，亲自决定经济、生产、科技和战争机器如何成型。

### 开局

- T1基础能力；
- 指挥/建造核心、基础电力与最小采集链；
- 10%—15%有效指挥容量的工程、侦察、步兵和轻型机动力量；
- 不预置高级生产/科技体系。

### 乐趣

经济扩张、快攻、科技冲刺、代理基地、海空绕后、体系斩首都必须可行。主基地被毁不自动结束；只要存在真实重建路径，玩家仍可翻盘。

胜利来自敌方战争组织能力不可恢复地崩溃，不需要清理最后一个单位。

## 征服

### 定位

主竞技地图控制模式。战略区域不是抽象计分圈，而是工业区、机场、港口、数据中心、能源、交通、高地等真实战争资产。

### 开局

- T1完整，并具有征服所需基础信息化/侦察共享能力；
- 基础生产、雷达和保障已经运行；
- 15%—25%有效指挥容量；
- 开局即有工程/占领、侦察、机械化和基础防空力量。

### 乐趣

玩家持续做“哪块区域真正值得拿、哪块可以放、如何维持连接、如何切断对方区域网络”的选择。

区域需要实际控制、指挥和保障连接才能稳定发挥价值。大范围占领会自然增加守备与物流压力，因此不会变成纯领土滚雪球。

## 前线

### 定位

玩家接手一条已经存在的现代战线，不从空地造第一座基地。重点是主攻轴、次要轴、预备队、炮兵/防空/EW支援和动态前线。

### 开局

- T1/T2完整，并拥有基础T3无人/机器人/协同能力；
- 后方基地、前线指挥、保障、防空和部分火力阵地已经存在；
- 30%—40%有效指挥容量；
- 至少两个独立战斗群；
- 初始军力中保留机动预备队，不能全部钉死在接触线上。

### 乐趣

动态前线允许正面突破、侧翼、包围、主动后撤、两栖、空降、修桥/断桥和敌后建立新保障轴线。

被包围部队不会受到“游戏化扣血”，真正压力来自弹药、维修、增援和交通被切断。

玩家可以把次要战线交给AI，自己集中指挥主攻或反击。

## 战区战争

### 定位

完整战争沙盘。玩家接手成熟战区，管理的是工业、后勤、多基地、多战线、海空和战略资源，而不是几辆初始车。

### 开局

- T1—T3完整；
- 部署阶段从本国合法方向中选择一套等价值T4战区建设包；
- 多个指挥/生产/保障节点；
- 地图允许时已有机场、港口、数据/AI和轨道接入设施；
- 40%—50%有效指挥容量；
- 主战方向、次要方向和战区预备队均有可用力量；
- L1—L4 AI全部开放。

### 乐趣

玩家发布“守住东线、夺取港口、封锁海域、保护工业走廊”等高层任务，AI负责拆解执行。

领土和工业扩张会增强战争能力，也同时拉长补给、增加守备、防空和交通压力。局部战败不直接等于整局结束。

非排位/私人战区可支持长局保存继续。

## 快速战争

### 定位

满战备综合对抗。它跳过发展准备阶段，不是“生产加速模式”，也不是新手模式。

### 开局

- T1—T5和全部正式国家特色科技完成；
- 所有地图允许的功能型建筑体系已经部署；
- 电力、算力、补给、机位和指挥网络处于完整战备；
- 陆军、航空、无人/机器人、火力、防空、EW、工程保障等均有足够编制；
- 海图同时拥有完整海军编队；
- L1—L4 AI和A1—A4自主能力可用；
- 现役军力65%—70%有效指挥容量，保留30%—35%用于补损和转型；
- 战略武器节点可预置，但高价值能力按正常初始充能状态开始。

### 乐趣

全科技后，成长从“科技树”转移为：战损、补充、编制转型、区域控制、基地功能节点损毁/重建、保障网络、情报/EW和战略武器状态。

部署前可在等价值预算内选择均衡、装甲、制空、无人、拒止或自定义编成。完整规格见 `../specs/QUICKWAR_FULL_READINESS.md`。

## AI统帅体验

AI负责减少无意义微操，不替玩家决定大战略。

- 歼灭：以编队、伴随、维修、侦察为主，高层AI随科技体系形成；
- 征服：守区、巡逻、工程保障、区域机动；
- 前线：战斗群执行、前线防守、掩护撤退、预备队待命；
- 战区：多线任务拆解、次要战线托管、海空巡逻、保障组织；
- 快速战争：从开局即可使用L1—L4，但必须由玩家设置任务、区域、预算和禁令。

玩家直接命令永远覆盖AI旧计划。AI默认报告事实，不依据比赛时长催促总攻、撤退或升级。

## 地图驱动力

地图不能只靠矿区推动争夺。机场、港口、雷达、数据中心、能源、物流、卫星站、桥梁、海底通信等必须提供真实价值。

模式地图重点不同：

- 歼灭：扩张空间、资源路线、多基地可能性；
- 征服：战略区域价值与多方向争夺；
- 前线：至少两条主作战轴和战略旁路；
- 战区：多战线、多域交通和纵深基础设施；
- 快速战争：足够大的安全部署区和完整基地/现役军队展开空间。

## 翻盘与防滚雪球

不使用免费资源补贴或时间惩罚。翻盘依靠真实战争逻辑：伏击、克制、切补给、摧毁雷达/数据/AI/机场、破坏交通、包围突出部、局部兵力集中和工业破袭。

优势方越扩张，会自然承担更长保障线、更大守备面、更广防空/传感覆盖和更多基础设施脆弱点。

## 玩家进入路径

满科技快速战争认知负担最高，不再作为新玩家默认入口。

推荐路径：

`教学/战役 -> 歼灭或征服 -> 前线 -> 战区战争 / 快速战争`

模式选择界面必须明确显示开局战备、建设深度、科技比重、地图控制、AI参与、规模和推荐经验。

## 防拖延

不通过倒计时、超时增益、资源衰减或伤害倍率结束比赛。

防止无意义拖局依靠战争状态：没有恢复路径的残余单位不能永久续局；围困、封锁、断交通、体系节点摧毁和战略控制都可以自然结束战争。超级武器属于玩家投资/战备体系，不承担系统强制收局职责。
