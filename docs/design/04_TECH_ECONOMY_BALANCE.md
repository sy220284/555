# 科技、经济与平衡

## 平衡基准

**征服 + 标准现代规则是多人主平衡基准。**

单位、建筑、科技、情报、电子战、AI和战略设施优先在该规则下验证长期价值。其他模式允许通过开局状态、规则深度和胜负目标产生偏离，但必须明确记录偏离项，不能形成互相独立的五套平衡体系。

## 五级科技

T1机械化；T2信息化；T3无人/机器人；T4智能化；T5未来化。T4开始科技分叉，每个国家标准对局只能高效发展少数高阶方向。

示例：中国从无人集群、远程拒止、机器军团、空天网络中优先两条；美国从隐身航空、战争AI、轨道、定向能中优先两条。

科技层级只由资源、建筑、研究前置和玩家投资推进。允许高风险快科技，也允许长期停留低科技；不存在按比赛分钟数开放的层级。

## 资源

- 工业资源：普通建筑、步兵、车辆、基础机器人、火炮。
- 战略资源：高级AI、机器人、航空、舰艇、卫星、终局能力。
- 战场数据：作为高级科技/情报后台资源，不长期占据主界面。
- 电力：建筑和高能能力基础约束。
- 指挥容量：限制总军力结构。
- 算力：限制AI自动化和高级机器人规模。

## 1v1基准

初始工业12000；战略资源2000。

经济规模按真实控制能力观察：

- 本地经济：约900—1600工业/分钟；
- 扩张经济：约1800—3200/分钟；
- 战区经济：约3500—5500+/分钟。

这些是经济规模区间，不对应固定比赛时间。玩家何时达到某一规模完全取决于扩张、控制和投入。

价格区间：基础步兵250—450；高级步兵600—1000；侦察机器人350—550；战斗机器人500—850；轻型车900—1400；步战车1200—1700；无人战车1500—2200；主战坦克1900—2800；自行火炮2400—3400；高级机器人2200—3500；重型机器人3500—5000；战斗机4500—7000；大型舰艇8000—18000。

## 指挥容量

标准初始300，扩展约500。步兵/小机器人1，轻车2，无人战车3，主战坦克/火炮4，高级机器人4—5，战机6，母平台8，大型舰艇12—18，战略单位20+。

## 算力超载

0—100%正常；100—125%反应下降；125—150%协同下降；150%+低优先单位转为本地自主模式。允许应急超载，但不可成为长期最优解。

## 自然节奏

经济和科技的节奏来自取舍：

- 多扩张换更高产能，同时增加守备和后勤负担；
- 快科技换更少的当前兵力；
- 大量低科技单位换取数量和地图覆盖；
- 高级机器人/航空换取更高战略资源、算力和保障成本；
- 长距离推进产生真实补给和交通成本。

禁止为了缩短平均局长而加入随时间变化的资源倍率、伤害倍率、科技解锁或强制追赶补贴。

## 综合价值模型

单位和建筑不得只看每秒伤害、生命和造价。内部分析统一采用多维价值框架：

`综合价值 = 直接战斗价值 + 信息价值 + 体系贡献 + 战略投射 + 生存/机动价值 - 资源成本 - 指挥成本 - 算力成本 - 后勤成本 - 操作负担`

各项不是要求最终压成一个公开数字，而是平衡审计维度。

### 直接战斗价值

伤害、射程、克制、生存、控制和局部战斗交换。

### 信息价值

发现、确认、锁定、目标共享、假目标识别、预警和远程火力质量提升。

### 体系贡献

对其他单位产生的间接增益，例如：

- 预警机提高航空与远程武器目标质量；
- 数据中心提高共享和AI反应；
- 电子战削弱对方传感/通信；
- 物流节点提高恢复和持续作战；
- AI节点减少低价值操作并提高战斗群执行效率。

### 战略投射

跨区域影响、快速机动、远程支援、海空覆盖、轨道/战略接入等。

### 隐性成本

高价值单位必须计算机场机位、补给、维修、算力、指挥容量、操作注意力和体系依赖，不允许只用工业造价平衡。

## 体系组合审计

任何长期高胜率组合都必须分析“单体正常、组合超模”的可能性。

重点观察：

- 预警 + 远程火力；
- 雷达/数据 + AI战斗群；
- 电子战 + 无人蜂群；
- 防空 + 远程火炮；
- 物流 + 重装甲持续推进；
- 多个国家特色模块叠加。

如果组合价值过高，优先调整体系依赖、成本、覆盖范围、信息质量或反制窗口，禁止简单把所有相关单位统一减伤害。

## 战斗节拍约束

平衡不能只追求数学交换相等，还必须满足 `03B_COMBAT_PACING_FEEDBACK.md`：

- 先手有价值但非必杀；
- 高价值单位有合理反应窗口；
- 机动、撤退和压制能改变结果；
- 克制可以从战场反馈中被理解；
- 远程强势体系至少受情报、弹药/补给、暴露和机动中的多项限制。

## 平衡原则

国家强的是打法，不是名字。单位价值同时计算火力、生存、机动、射程、感知、特殊能力与经济/容量/算力/后勤成本。

内部价值参考：基础步兵10；反装甲步兵18；侦察机器人12；战斗机器人18；步战车45；主战坦克100；自行火炮105；远程防空115；高级无人战车100；高端战斗机220；大型驱逐舰500。

这些模板只是直接/基础价值起点；辅助、情报和体系型单位必须额外计算信息与体系贡献，不能直接与纯火力单位按一个伤害指标比较。

健康胜率目标47%—53%；长期低于45%或高于55%必须按地图、段位、科技选择、经济规模、战略控制、体系组合和单位成本交换定位根因，禁止简单全局加减百分比。

对局时长、首次交战和科技到达时点可以记录，但只是诊断数据，不能直接成为调平衡时新增时间惩罚的依据。
