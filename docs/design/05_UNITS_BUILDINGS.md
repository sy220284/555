# 单位与建筑规格总览

## 陆军

步兵：基础战斗班、反装甲、防空、侦察、工程、电子战、特种部队。

装甲：侦察车、步兵战车、主战坦克、重型平台、无人战车。

火力：迫击炮、自行火炮、远程火箭、巡飞武器、战术远程火力。

支援：防空、电子战、指挥、维修、工程、机器人/无人母平台。

## 机器人四大玩家类别

1. 侦察：标记目标、城市/地下探索、危险区域观察。
2. 战斗：四足、人形或小型火力平台，用于城市、伴随、警戒。
3. 支援：工程、排雷、维修、运输、补给统一在此类。
4. 重型：无人战车、多足重火力和母平台，用于突破与防守。

普通阵营不普及巨大人形机甲；结构优先履带、轮式、四足/六足、低重心多足。尤里可出现更夸张的生物机械。

## 建筑

核心：战区指挥中心、人员中心、地面装备厂、无人系统中心、机器人制造中心、航空基地、海军基地、能源站、数据中心、雷达节点、AI 战斗指挥中心、战略计算中心、卫星通信、保障中心、前线保障、空天作战中心、发射场。

基地采用分布式节点。摧毁单一节点削弱某一体系，不能让玩家“一栋建筑被炸全军停机”。

## 防御

自动武器站、反装甲炮塔、反无人阵地、近/中/远程防空、反导、电子战节点、假目标、地下掩体。禁止万能塔。

## 经典未来科技现代化

- 光棱：激光反无人 → 高能定向能 → 棱镜协同 → 光棱体系。
- 磁暴：电子战 → 高功率微波 → 区域电磁压制 → 磁暴体系。
- 铁幕：改为区域主动防护场，提供高减伤、电磁与传感器保护，不提供绝对无敌。

## 内容设计门槛

新单位必须有唯一战术角色、清晰轮廓、明确反制和不可被现有单位无损替代的理由。否则不进入内容池。
