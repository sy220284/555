# 单位与建筑规格总览

## 陆军

步兵：基础战斗班、反装甲、防空、侦察、工程、电子战、特种部队。

装甲：侦察车、步兵战车、主战坦克、重型平台、无人战车。

火力：迫击炮、自行火炮、远程火箭、巡飞武器、战术远程火力。

支援：防空、电子战、指挥、维修、工程、机器人/无人母平台。

## 机器人四大玩家类别

1. 侦察：标记目标、城市/地下探索、危险区域观察。
2. 战斗：四足、人形或小型火力平台，用于城市、伴随、警戒。
3. 支援：工程、排雷、维修、运输、补给统一在此类。
4. 重型：无人战车、多足重火力和母平台，用于突破与防守。

普通阵营不普及巨大人形机甲；结构优先履带、轮式、四足/六足、低重心多足。尤里可出现更夸张的生物机械。

## 建筑

核心：战区指挥中心、人员中心、地面装备厂、无人系统中心、机器人制造中心、航空基地、海军基地、能源站、数据中心、雷达节点、AI战斗指挥中心、战略计算中心、卫星通信、保障中心、前线保障、空天作战中心、发射场。

基地采用分布式节点。摧毁单一节点削弱某一体系，不能让玩家“一栋建筑被炸全军停机”。

## 战略设施价值模型

机场、港口、雷达、数据中心、能源、物流、卫星站、桥梁和通信节点必须足够重要到值得改变主攻方向，但不能成为唯一必抢点。

每类设施至少定义四个阶段：

`正常收益 → 受损降级 → 完全失效后果 → 恢复路径`

设计原则：

- 正常：提供清晰可理解的体系收益；
- 受损：逐步降低效率，而非瞬间从100%掉到0；
- 失效：削弱相关体系，但保留最低本地作战能力；
- 恢复：工程、维修、重建或替代节点能够重新建立能力。

示例：

- 机场：正常提供完整机位/整备；受损减少机位和整备效率；失效后无法补充维护，但空中现有飞机不凭空消失；修复后逐步恢复。
- 雷达：正常提供区域侦察与目标质量；受损降低刷新/精度；失效后依靠光学、无人和友军本地传感；修复后恢复共享。
- 数据中心：正常提高融合和AI反应；受损增加共享延迟；失效后战斗群只能使用本地/边缘节点能力；重建可恢复。
- 物流：正常提高补给/维修；受损降低恢复速度；失效后前线依靠现有库存和其他路线；重新连接后恢复。
- 桥梁/交通：正常提供高效通路；受损降低通行能力；封闭迫使绕行/架桥；工程可修复或建立临时路线。

## 战略设施与地图

战略设施价值必须通过地图结构体现：

- 同一功能通常不只存在一个全局唯一节点；
- 高价值设施附近必须有进攻与反制路线；
- 设施收益与守备/暴露成本匹配；
- 失去设施应改变打法，而不是直接宣判失败；
- 战略设施效果优先作用于战争体系，不直接提供无条件伤害倍率。

## 防御

自动武器站、反装甲炮塔、反无人阵地、近/中/远程防空、反导、电子战节点、假目标、地下掩体。禁止万能塔。

## 经典未来科技现代化

- 光棱：激光反无人 → 高能定向能 → 棱镜协同 → 光棱体系。
- 磁暴：电子战 → 高功率微波 → 区域电磁压制 → 磁暴体系。
- 铁幕：改为区域主动防护场，提供高减伤、电磁与传感器保护，不提供绝对无敌。

## 单位角色门槛

新单位必须同时回答：

1. 它解决什么战术问题；
2. 玩家从正常RTS镜头如何一眼识别；
3. 它被什么克制；
4. 它提供的是直接战斗价值、信息价值、体系贡献还是战略投射；
5. 为什么现有单位不能无损替代；
6. 它增加多少玩家操作、AI决策和资产成本。

如果只能通过“数值更高”“科技更晚”“模型更酷”解释存在价值，不进入正式内容池。

## 内容设计门槛

新单位必须有唯一战术角色、清晰轮廓、明确反制和不可被现有单位无损替代的理由。否则不进入内容池。

任何新单位/建筑都必须同时遵循 `03B_COMBAT_PACING_FEEDBACK.md` 和 `../specs/SYSTEM_COMPLEXITY_BUDGET.md`，不能为了增加现代战争名词而制造不可读的功能重叠。
