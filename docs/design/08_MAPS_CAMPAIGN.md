# 地图、战区与战役

## 九大战区

西太平洋（岛链/海空/反舰）、东欧（装甲/炮兵/无人/电子战）、中东（沙漠/城市/导弹/地下设施）、欧洲城市群（城市战/工业）、北极（潜艇/预警/极端环境）、印度洋（远洋舰队/补给）、北美（高科技设施/尤里渗透）、中亚（纵深/机动/远程火力）、尤里核心区（深海/极地/地下/轨道节点）。

## 地图规模

竞技 6×6—10×10 公里；大型 12×12—16×16；24×24+ 只用于战略娱乐。距离按游戏节奏压缩，不追求真实比例。

## 16 张首发多人地图

1v1：灰原试验场、裂谷节点、北方平原、数据争夺、沙海双城、极昼前线。

2v2/3v3：钢铁平原、第聂伯防线、海峡封锁、莱茵钢铁带。

海陆空综合：第一岛链、深蓝壁垒、印度洋之盾。

大型娱乐：大陆腹地、东部之盾。

空天实验：轨道黎明。

竞技地图至少有两条主要推进线、一条侧翼、多处战略设施；资源距离、主攻距离、地形优势需自动检测出生偏差。

## 动态环境

桥梁破坏、建筑坍塌、道路阻断、森林燃烧、弹坑、浮桥、临时跑道、野战工事。天气可影响光学侦察、航空/无人效率等，但不能靠随机直接决定胜负。
