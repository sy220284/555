# 地图、战区与战役

## 九大战区

西太平洋（岛链/海空/反舰）、东欧（装甲/炮兵/无人/电子战）、中东（沙漠/城市/导弹/地下设施）、欧洲城市群（城市战/工业）、北极（潜艇/预警/极端环境）、印度洋（远洋舰队/补给）、北美（高科技设施/尤里渗透）、中亚（纵深/机动/远程火力）、尤里核心区（深海/极地/地下/轨道节点）。

## 地图规模

竞技 6×6—10×10 公里；大型 12×12—16×16；24×24+ 只用于战略娱乐。距离按游戏节奏压缩，不追求真实比例。

## 地图生产顺序

16张首发地图的设计全部保留，但正式实现禁止同时铺开。

### 第一阶段：`MAP_GRAY_RANGE`

灰原试验场是第一张完整可玩和数值基准图，优先验证：

- 基础建设与采集；
- 陆战移动/共享导航；
- `03B_COMBAT_PACING_FEEDBACK.md` 的完整局部战斗节拍；
- 情报/战争迷雾；
- AI授权与接管；
- 战略设施争夺；
- 歼灭完整战争能力判负；
- 后续征服母玩法所需的控制区域基础。

该图在真正可玩前，不以扩张其余15图作为主要进度。

### 第二阶段：第二张结构差异图

`MAP_RIFT_NODE` 或同等级桥梁/多路线图，用于证明共享战争模型能处理交通破坏、绕行、工程恢复和不同战略轴线。

### 第三阶段：核心竞技地图集

征服母玩法稳定后扩展1v1和2v2核心排位地图。

### 第四阶段：海陆空和大型战区

海军、轨道和大型战区只在基础陆战、AI、战略设施和性能门禁稳定后扩张。

## 16 张首发多人地图

1v1：灰原试验场、裂谷节点、北方平原、数据争夺、沙海双城、极昼前线。

2v2/3v3：钢铁平原、第聂伯防线、海峡封锁、莱茵钢铁带。

海陆空综合：第一岛链、深蓝壁垒、印度洋之盾。

大型娱乐：大陆腹地、东部之盾。

空天实验：轨道黎明。

竞技地图至少有两条主要推进线、一条侧翼、多处战略设施；资源距离、主攻距离、地形优势需自动检测出生偏差。

## 战略设施地图规则

机场、港口、雷达、数据中心、能源、物流、卫星站、桥梁等必须具备真实战争功能，并遵循统一状态逻辑：

`正常收益 → 受损降级 → 失效后果 → 恢复路径`

地图设计必须满足：

- 高价值设施值得争夺，但不能成为唯一胜利路线；
- 同类关键功能通常存在替代节点或恢复方式；
- 进攻方夺取设施的收益与守备/物流压力匹配；
- 设施被毁后应改变战法，不直接让一方全军瘫痪；
- 战略设施周围至少存在一种正面以外的反制方式，例如绕行、远程压制、断供或工程恢复。

## 动态环境

桥梁破坏、建筑坍塌、道路阻断、森林燃烧、弹坑、浮桥、临时跑道、野战工事。天气可影响光学侦察、航空/无人效率等，但不能靠随机直接决定胜负。

## 战役生产顺序

24关数量冻结，不继续扩量。

首先完成 `MIS_01` 的全链路灰盒：

`任务状态 → 玩家操作 → AI → 战斗 → 存档/加载 → 过场跳过 → 音频占位 → 胜负结算`

`MIS_01` 通过后才能批量复制任务生产路径到后续关卡。

每个章节优先让玩家实际操作一个核心系统，而不是只通过对白解释：

- 序章：基础战斗、侦察、误判；
- 联合防卫：情报、假目标、AI污染；
- 中国：分布式体系、防空反导、无人协同；
- 欧亚：电子黑区、持续工业、机器前线；
- 尤里：异常体系与其弱点；
- 最终关：把地面、海空、AI、情报和战略节点组织成联合决战。

## 地图身份原则

不同战区不能只是换地表材质。每张正式地图至少有一个决定玩法身份的结构：

- 岛链：机场、岛屿、舰队、反舰链；
- 东欧：桥梁、铁路、平原、炮兵阵地；
- 城市：高楼遮蔽、街区、数据节点、地下/绕行路线；
- 北极：预警站、稳定陆桥、极端传感环境；
- 工业区：交通、能源、数据和生产设施网络。

玩家只看战略图和地形截图，也应大致理解该图鼓励什么战争方式。
