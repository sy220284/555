# 美术、界面、特效与音频

## 美术总原则

真实技术逻辑 + 红警式夸张轮廓。不能做成所有载具都相似的照片级军武模拟。正常 RTS 缩放高度必须能一眼分辨坦克、炮兵、防空、电子战、机器人、无人母车和超级单位。

## 视觉语言

联合防卫：白/灰/蓝，锐利、航空化、低可探测轮廓。

中国：深灰/黑/红识别线，模块化、稳定几何、大型阵列。

欧亚：深绿/黑/暗红，厚重、工业、装甲化。

尤里：黑/紫/暗金，生物机械、多足、非对称、异常运动。

机器人进一步用结构区分：高端体系传感器密度高；工业体系强调低矮模块化；欧亚强调粗壮耐用；尤里强调生物机械。

## 特效优先级

炮火、导弹尾迹、防空拦截、无人蜂群、激光、磁暴、电磁干扰、爆炸冲击和分阶段建筑破坏。竞技模式自动减少浓烟、闪光、震屏和视野遮挡。

## UI

常驻仅显示：工业资源、战略资源、电力、指挥容量、算力。后勤、干扰、卫星等以状态提示和可选图层呈现。

高级图层：情报、电子战、AI 指挥、后勤、轨道。

AI 指挥界面允许画防守/攻击/侦察/巡逻/禁入/火力支援区，设置预算、风险和风格，并随时接管。

## 镜头

俯视、自由旋转、战略缩放、战区视图、轨道战略视图。保持 RTS，不加入第一/第三人称直接作战。

## 音频

建立武器听觉识别：坦克炮、火箭、近防、无人机、激光、磁暴、超级武器需有清晰声纹。配乐以工业、电子、军事、未来为核心，避免普通电影式管弦成为唯一主风格。
