# 数据驱动与内容定义

## 核心原则

单位、武器、建筑、国家、科技、能力、地图规则、AI 参数必须配置化。程序只实现通用能力，不为单一国家写长期分支。

## 稳定定义

建议核心对象：`FactionDefinition`、`CountryDefinition`、`UnitDefinition`、`BuildingDefinition`、`WeaponDefinition`、`TechDefinition`、`AbilityDefinition`、`MapRuleDefinition`、`AIProfileDefinition`。

## 单位字段

稳定 ID、显示键、所属基础体系、国家限制、生产建筑、成本、时间、指挥容量、算力、电力依赖、生命/装甲、速度、传感器、通信、自主等级、武器、能力、标签、模型/特效/音频引用。

## 武器字段

伤害、伤害类型、射程、射速、弹道、弹速、精度、穿透、目标标签、锁定等级、弹药/冷却、最小射程、特效/音频。

## 修正器

国家特色、科技、老练度、AI/网络状态都通过可组合修正器处理。修正顺序必须稳定、可测试、可解释。

## 版本与迁移

所有数据包带 `schema_version`；字段废弃需提供迁移策略。存档/录像记录数据版本与内容哈希，版本不兼容时明确拒绝或迁移，禁止静默错误。

## 数据验证

持续集成至少检查：ID 唯一、引用存在、成本非负、科技无循环、生产链可达、单位存在反制标签、资源/容量字段完整、模式关闭某系统后仍有合法路径。

## 模组

官方数据和模组共用定义格式；竞技只加载官方签名/哈希集合，自定义房间可加载模组。
