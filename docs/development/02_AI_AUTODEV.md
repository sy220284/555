# AI 全量自动开发推进模式

## 1. 总体模式

取消“先原型后量产”的串行项目管理。完整游戏骨架、系统接口、稳定ID和自动门禁从第一天建立；功能按：

`placeholder -> playable -> content_complete -> ship_ready`

持续替换和收口。

地图额外使用：`layout_defined -> graybox_ready`。

任何代理不得把“文档写完、占位可跑、灰盒可玩”汇报成最终完成。

## 2. 代理角色

- 总控代理：任务依赖图、优先级、阻塞、状态真实性。
- 架构代理：模块边界、公共接口、技术栈、迁移审批。
- 模拟代理：经济、科技、状态和固定tick。
- 战斗代理：武器、伤害、弹道、主动防护。
- AI/机器人代理：玩家AI、敌方AI、自主等级、算力。
- 导航代理：分层寻路、流场、局部避障、空间索引。
- 情报/EW代理：战争迷雾、传感器、电子/网络战。
- 多域代理：空军、海军、轨道。
- 网络代理：Transport、相关性、快照、重连、录像。
- 图形代理：URP、Entities Graphics、GPU批量表现、VFX。
- UI/无障碍代理：输入、战术图层、字幕、可访问性。
- 音频代理：AudioEventBus、WarAudioDirector、FMOD、音效/语音/音乐生产。
- 地图代理：`.map.json`、灰盒、导航、公平性、正式地图集成。
- 战役代理：任务状态机、剧情、对白、过场、存档。
- 在线服务代理：账号、组队、匹配、排位、结果、赛季、遥测。
- 安全代理：认证、反作弊、秘密、供应链、隐私、攻击测试。
- 数值代理：经济、胜率、成本交换和平衡建议。
- 测试代理：单元、集成、压力、性能、网络、安全回归。
- 内容代理：数据、模型、材质、动画、音频资产、本地化与来源追溯。
- 集成代理：跨模块冲突、接口迁移、主线合并。

## 3. 任务图

所有需求拆成明确：

`输入 -> 依赖 -> 输出 -> 验收 -> 回归门禁`

接口定义完成即可允许下游并行，不等待上游全部正式资产完成。

依赖不完整时使用同接口占位实现，但必须保留真实状态标签。

## 4. 分支/工作树

每项开发使用独立分支和工作树。代理默认只能修改模块所有权目录；跨模块变更通过接口变更请求或集成代理处理。

稳定ID/Schema/协议等共享契约变更必须同步所有消费者和迁移规则。

## 5. 自动循环

```text
领取任务
→ 读取AGENT + 上位/专项规格
→ 验证输入/ID/依赖
→ 实现
→ 本地测试
→ 静态/数据检查
→ 提交
→ CI
→ 失败定位与最小修复
→ 集成
→ 性能/可复现/网络/安全/平衡验证
→ 更新文档与状态
→ 领取下一任务
```

## 6. 自动回退

主线出现以下任一情况立即阻止继续扩散并建立修复任务：

- 编译/启动失败；
- P0测试失败；
- 权威重放分叉；
- 隐藏信息泄露；
- 严重性能回退；
- 稳定ID/Schema悬空；
- 高危安全问题；
- 正式资产许可来源缺失。

可以安全回退时回退问题提交；禁止让主分支长期陪同故障停摆。

## 7. AI修改红线

- 测试失败先最小复现和根因修复，禁止第一反应重写大模块。
- 禁止为提高胜率破坏国家玩法差异。
- 禁止自行改变世界观、四大体系、AI权限、五级科技、首发边界。
- 禁止自行提高最低硬件来掩盖性能问题。
- 禁止自行替换冻结引擎/网络/音频关键技术栈。
- 禁止根据名称猜缺失武器、能力、地图坐标、任务逻辑；缺规格先补规格。
- 禁止把生成式资产投入正式构建却没有来源和商业授权记录。

架构大改必须先更新ADR/架构文档并经架构代理审批。

## 8. 内容自动生产

### 地图
读取 `MAP_SPECS.md` + `MAP_LAYOUT_RUNTIME_SCHEMA.md`，先生成侧车数据和确定性灰盒，再跑公平/导航门禁；没有 `.map.json` 不得标 `graybox_ready`。

### 战役
读取任务规格与叙事默认契约，生成任务状态机、占位对白和测试；正式对白、配音、过场单独追踪 `content_complete`。

### 音频
按 `AUDIO_VOICE_PIPELINE.md` 批量生成候选、质检、来源登记、FMOD事件和游戏内验收；生成成功不等于资产通过质量门禁。

### 数据
所有 `UNIT_/FORM_/BLD_/WPN_/TECH_/ABL_/STRAT_` 必须通过内容验证器引用闭环，禁止匿名运行时定义。

## 9. 进度模型

持续记录：

- 规格完整率；
- 代码实现率；
- 自动测试通过率；
- P0/P1/P2/P3缺陷；
- 性能状态；
- 地图 `layout_defined/graybox_ready` 数量；
- 战役可通关数量；
- 正式美术/音频/配音覆盖率；
- 在线服务可用率；
- 安全门禁状态；
- `content_complete/ship_ready` 覆盖率；
- 未闭环依赖与阻塞。

不以“阶段名字看起来完成”代替实际验收数据。

## 10. 代理记忆

每个模块维护 `MODULE.md`、ADR、已知问题和性能基线。代理接管前先读取已有决策，避免重复研究、反复换技术路线和重新踩已解决问题。

重复工作必须沿用已验证行动路径，除非已有证据证明路径失效。
