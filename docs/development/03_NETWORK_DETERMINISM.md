# 确定性、网络、录像与重连

## 模式

核心采用确定性模拟 + 指令同步 + 服务器校验。网络不高频同步几千单位位置，而同步玩家/AI 命令、关键事件和状态哈希。

## 确定性规则

- 固定 30Hz 模拟步长。
- 所有随机来自显式种子与可编号随机流。
- 不使用系统时间影响玩法。
- 不依赖线程完成顺序或无序容器遍历顺序。
- 浮点若不能保证跨平台一致，核心模拟改用确定数学封装/定点或严格约束路径。

## 门禁

同地图、同种子、同命令流运行 10000+ 帧，多实例最终状态哈希必须一致。任何 Gameplay/Simulation/AI 变更都要运行此测试。

## 服务器职责

匹配、房间、命令转发、反作弊验证、状态哈希、周期快照、重连、观战许可。服务器不应成为每单位 30Hz 全状态转发器。

## 断线重连

加载最近可信快照 → 重放快照后的命令 → 对比状态哈希 → 恢复现场。超出允许窗口或内容哈希不一致时拒绝恢复。

## 录像

录像保存版本、内容哈希、地图、种子、初始状态与命令流。录像必须可用于 BUG 复现、平衡统计和观战；禁止把录像当视频文件保存。

## AI 同步

竞技中的 AI 决策必须确定性。可同步高层 AI 命令而非每个内部思考状态，但同一输入必须产生一致结果。
