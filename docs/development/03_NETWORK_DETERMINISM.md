# 网络、可复现模拟、录像与重连

## 1. 正式模式

联网采用：

**专用服务器权威模拟 + Unity Transport + 项目自研大规模 RTS 相关性/快照复制层。**

不再采用“所有客户端持有完整隐藏世界并纯锁步同步”的方案。

原因：本游戏存在战争迷雾、潜艇、雷达、卫星、隐身、假目标和尤里认知欺骗。真实隐藏状态不应发送给未获得情报的客户端。

## 2. 权威流程

```text
玩家输入
→ 客户端命令
→ Unity Transport
→ 服务器验证
→ 30Hz权威模拟
→ 情报/空间/重要度过滤
→ 批量增量状态
→ 客户端插值与有限预测
```

服务器是：

- 单位真实位置；
- 隐蔽状态；
- 伤害；
- 资源；
- 科技；
- AI；
- 机器人；
- 战争迷雾；
- 胜负判定

的唯一权威来源。

## 3. 客户端不得获得的状态

未满足对应情报条件时禁止发送：

- 未侦察敌军真实位置；
- 潜艇真实状态；
- 隐身单位真实状态；
- 假目标背后的真实身份；
- 尤里认知攻击的隐藏判定；
- 未公开敌方生产/科技队列；
- 未被发现轨道/传感器信息。

客户端只收到其当前情报权限允许显示的数据。

## 4. 传输层

采用 Unity Transport 正式版本作为底层。

通道至少区分：

- 可靠有序：玩家命令、科技、建筑、关键事件；
- 可靠状态：重连、关键快照、任务状态；
- 非可靠时效状态：位姿、低价值动态数据；
- 独立遥测：非游戏关键统计。

## 5. 自定义复制层

批量复制必须支持：

- 空间相关性；
- 战斗重要度；
- 情报可见性；
- 单位类别；
- 与摄像机/玩家控制区距离；
- 状态是否变化；
- 同战斗群聚合。

允许不同频率：

- 近距离交战单位：高频；
- 远距离已知单位：中低频；
- 静态建筑：事件/低频；
- 未侦察敌军：0Hz，不发送。

数据格式采用：

- 量化位置/方向；
- 位字段；
- 状态增量；
- 基线快照；
- 批量数组；
- 战斗群共享字段。

禁止每实体每帧高层 RPC。

## 6. Netcode for Entities 定位

Netcode for Entities 可用于原型、参考和局部工具验证，但当前不冻结为正式生产复制核心。

只有经过项目实际基准证明其在以下目标全部优于自研复制层后，才允许升格：

- 1500+活动实体；
- 战争迷雾数据隔离；
- 服务器CPU；
- 带宽；
- 重连；
- 调试复杂度；
- AI自动编程可维护性。

## 7. 固定模拟

服务器权威模拟固定 30Hz。

规则：

- 显式时间步；
- 不使用系统墙钟时间决定玩法；
- 随机来自显式种子和编号随机流；
- 并行任务固定阶段归并；
- 线程完成先后不得改变规则结果。

## 8. 可复现性

不要求不同客户端本地重算整个世界。

但要求：

> 同一个服务器构建、同一初始快照、同一命令/事件流，应重放到一致的关键状态哈希。

关键状态包括：

- 资源；
- 科技；
- 生命；
- 单位状态；
- 位置量化值；
- AI任务；
- 机器人自主/算力；
- 胜负。

经济、伤害、科技等优先整数/定点；运动和几何允许受严格约束的量化浮点。

## 9. 状态哈希

服务器定期生成：

- 全局内部哈希；
- 关键子系统哈希；
- 可见状态哈希。

用于：

- 自动测试；
- 录像验证；
- 重连；
- BUG定位；
- 服务器异常检测。

## 10. 重连

流程：

```text
客户端重新认证
→ 获取当前比赛版本/内容哈希
→ 下载最近授权快照
→ 接收快照后增量事件
→ 客户端重建表现状态
→ 恢复控制
```

客户端重连快照仍然只包含其有权获得的状态。

服务器内部保存完整权威快照。

## 11. 录像

正式比赛录像分两类：

### 权威复盘录像

服务器保存：

- 版本；
- 内容哈希；
- 地图；
- 初始随机种子；
- 周期关键快照；
- 玩家命令；
- 必要权威事件。

用于完整复现、BUG和平衡分析。

### 玩家视角录像

可记录特定玩家当时实际获得的情报，避免回放泄露原比赛中不可见信息。

## 12. 观战

观战权限由服务器决定：

- 玩家视角；
- 队伍视角；
- 延迟全图赛事视角；
- 管理员/裁判视角。

全图观战默认增加延迟，防止向参赛玩家传递隐藏情报。

## 13. AI同步

AI运行在权威服务器。

客户端只接收 AI 产生的可见战争结果，不需要同步 AI 内部完整黑板或规划树。

AI决策必须可以通过服务器录像和日志复现关键原因。

## 14. 服务器构建

采用 Unity Dedicated Server 正式构建目标，Linux x64 为首要部署平台。

服务端移除/不加载：

- 高精材质；
- VFX；
- 音频；
- 客户端动画；
- UI。

只保留模拟、AI、导航、碰撞简化数据、网络、存档、录像和反作弊所需内容。

## 15. 门禁

任何网络/Simulation/AI重要变更至少通过：

- 30分钟长局重放一致性；
- 丢包/抖动/延迟测试；
- 断线重连；
- 1500活动实体带宽测试；
- 战争迷雾泄露测试；
- 潜艇/隐身/假目标泄露测试；
- 服务器性能测试；
- 录像可复现测试。

网络优化不得通过向客户端发送隐藏真实状态换取实现方便。
