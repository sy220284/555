# 性能、大规模单位与导航

本文件与 `technical/HARDWARE_PERFORMANCE_TARGETS.md`、`technical/PERFORMANCE_ARCHITECTURE.md`、`technical/TECH_STACK.md` 一致。任何旧硬件基线、Unreal/Actor/Chaos 描述均视为废弃。

## 1. 核心原则

项目性能目标不是靠降低画质、减少单位或削弱AI兜底，而是从架构、算法、数据结构、资产预算和批处理上减少无效工作。

冻结规则：

1. 最低完整体验以2026主流游戏电脑为基准。
2. 标准画质是基础产品路径，不是高配特权。
3. 同一模式下，不同硬件执行相同权威模拟、AI、单位数量、情报、电子战、机器人和伤害规则。
4. 任何降频必须是设计层固定多速率更新，不得按玩家机器快慢动态改变规则。
5. 高端硬件提高分辨率、刷新率、视觉采样精度和战区娱乐规模，不负责补齐基础功能。

## 2. 最低完整体验基线

最低目标机：

- 现代6核12线程级CPU，参考 Ryzen 5 5600 / Core i5-12400F 或同级；
- 16GB双通道内存；
- RTX 3060 / RTX 4060 / RTX 5060 / RX 7600 同级，8GB+显存；
- NVMe SSD；
- 1080P标准画质；
- 标准现代模式800—1500有效活动实体；
- 常规目标60FPS，高密度瞬时交战1% Low目标不低于约45FPS；
- 完整启用AI指挥、机器人、电子战、战争迷雾、空军和标准破坏反馈。

更详细硬件和标准画质定义以 `technical/HARDWARE_PERFORMANCE_TARGETS.md` 为唯一上位依据。

## 3. 模拟预算

权威服务器固定30Hz，单tick上限33.33ms。

标准现代对局目标：

- 平均模拟耗时 <= 10ms；
- P95 <= 16ms；
- P99 <= 22ms。

大型战区：

- 3000实体 P95 <= 25ms；
- 5000实体 P95 <= 33ms；
- 10000+只作为压力目标，不作为普通玩家基线。

初始模块预算：

- 实体移动/状态 <= 2.5ms；
- 导航 <= 3ms；
- AI <= 2.5ms；
- 战斗/弹道 <= 2.5ms；
- 感知/战争迷雾/电子战 <= 2ms；
- 经济/后勤/脚本/其他 <= 2ms。

预算可按实测重分配，但不得通过改变规则精度换预算。

## 4. 数据导向

普通作战单位采用 Entities/DOTS 轻量组件，不使用每单位复杂 GameObject/MonoBehaviour 作为权威状态。

热数据示例：

```text
EntityId
Position
Velocity
Heading
Health
Order
Target
WeaponState
SensorState
SupplyState
```

要求：热冷数据分离、Chunk友好、Burst可编译、热路径零GC、字符串和托管集合不得参与高频循环。

模拟世界存在5000单位，不等于场景存在5000个高成本表现对象。表现层按距离、重要性和类型使用 Entities Graphics、批量实例、共享骨架和少量特殊 GameObject。

## 5. 任务并行

建议固定阶段：

```text
输入/命令
→ 意图与高层规划
→ 导航/局部避障
→ 空间索引提交
→ 感知/EW
→ 武器/弹道
→ 伤害结算
→ 状态归并
→ 网络快照
```

并行任务写局部缓冲区并按固定规则归并；线程完成顺序不能影响玩法结果。

## 6. 事件驱动与脏区

禁止每tick全局轮询所有系统。

事件示例：敌人进入传感器范围、目标死亡、桥梁损坏、补给状态变化、通信下降、科技完成、建筑完工。

区域系统只更新受影响网格。桥梁被毁时仅使相关区域图、路径缓存和交通流失效，禁止全图重建。

## 7. 统一空间索引

感知、电子战、目标搜索、局部避障、爆炸、补给和AI威胁判断共享统一空间查询基础设施。

推荐：

```text
战略粗网格
→ 局部细网格/空间哈希/BVH
```

查询顺序：粗筛 → 阵营/标签位掩码 → 距离平方 → 必要时精确遮挡/视线。

禁止各系统各自扫描全实体。

## 8. 分层AI

正式固定频率：

- 战略AI：1—2Hz；
- 战区AI：2—5Hz；
- 战斗群AI：5—10Hz；
- 单位轻量控制：10—15Hz；
- 局部避障：10—20Hz；
- 紧急反应：事件触发。

这些频率属于游戏规则，不随客户端硬件改变。

AI成本应主要随战区和战斗群数量增长，单位控制器不得重复做全局规划。

## 9. 分层导航

正式结构：

```text
战略区域图
→ 道路/桥梁/山口连接图
→ 战斗群共享路径走廊
→ 局部流场/导航场
→ 空间哈希局部避障
```

禁止每单位独立全地图A*。

要求：

- 同战斗群共享高层路径；
- 相同起终区域缓存路径；
- 路径缓存带地形/道路版本号；
- 大编队提前估算通道容量；
- 地面、两栖、海军、航空使用各自简化层；
- 动态阻塞只触发局部失效。

## 10. 感知、战争迷雾与电子战

采用瓦片化影响区域和位集批处理，避免 O(N²)。

- 静态雷达/EW源预计算基础覆盖；
- 移动源只更新跨越的脏瓦片；
- 同一候选集供雷达、火控和AI复用；
- 最后一步才执行昂贵视线判断；
- 权威情报状态与画面迷雾分离。

## 11. 战斗与弹道

权威战斗使用自研轻量2.5D几何与弹道。Unity PhysX只用于非权威视觉碰撞、残骸和装饰反馈。

逻辑弹道与视觉弹道解耦：

- 高频机炮按批次/时间窗结算；
- 远程火炮使用解析轨迹/稀疏采样；
- 导弹共享阶段逻辑和空间查询；
- 爆炸只查询受影响空间格。

画面仍完整显示炮弹、尾迹、爆炸和拦截，不因逻辑优化减少玩家感知的战争规模。

## 12. 机器人与蜂群

群体共享任务、路线、目标候选、威胁场和部分传感结果；单体只处理局部位置、武器和安全反应。

机器人玩法中的“算力”是游戏资源，不能和真实CPU负载绑定。

## 13. 渲染与动画

标准路径：URP + Entities Graphics + BatchRendererGroup/间接实例化 + 项目GPU批量表现。

规则：

- 限制材质槽与透明过绘；
- 大量同类单位实例化；
- 共享主材质、纹理数组/图集；
- 车辆炮塔/传感器优先程序化动画；
- 大量步兵/机器人使用共享骨架、动画实例化、顶点动画或GPU友好方案；
- 远距离动画允许降采样和插值，但不得改变视觉语义；
- 主要动态阴影、炮火、导弹、爆炸、天气和建筑损伤在标准画质完整存在。

## 14. 内存与流送

- Addressables区域流送；
- mip流送；
- 共享资源和固定容量缓存；
- 音频流式加载；
- 路径/感知/威胁缓存设容量和淘汰策略；
- 录像采用命令/事件流+周期压缩快照；
- 禁止无限增长的常驻历史。

16GB机器必须完成标准现代对局90分钟长稳测试，无持续线性内存增长。

## 15. 网络性能

服务器权威30Hz；客户端只获得情报权限允许的状态。

- 近距离交战高频；
- 远距离已知目标低频；
- 静态对象事件驱动；
- 未侦察真实目标不发送；
- 批量状态增量、量化和位打包；
- 网络状态与视觉插值解耦。

禁止逐实体逐帧高层远程调用。

## 16. 性能优化顺序

1. 删除无效轮询和重复计算；
2. 事件驱动与脏区更新；
3. 降低算法复杂度；
4. 空间索引缩小候选；
5. 共享路径/感知/威胁/编队结果；
6. ECS热冷数据布局；
7. Burst/批处理/向量化；
8. Job并行；
9. 减少结构变更和主线程同步；
10. 渲染/动画/VFX/音频批量化；
11. 以上全部证明不足后，才允许提出设计预算变更。

## 17. 强制基准场景

- 800混合单位标准1V1；
- 1500混合单位高密度城市战；
- 1000坦克同步移动；
- 1000无人机蜂群；
- 300枚导弹+200次防空拦截；
- 3000实体团队战；
- 5000移动实体跨桥/绕路；
- 90分钟长局；
- 最低目标机1080P标准画质。

任何关键系统提交造成基准P95回退超过10%必须调查；超过20%默认阻断合并，除非性能预算文档明确批准。
