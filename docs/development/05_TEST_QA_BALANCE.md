# 测试、QA 与自动平衡

## 测试金字塔

单元测试：数学、资源、伤害、修正器、科技前置、序列化。

系统测试：生产、战斗、导航、机器人失联、算力过载、电子战、AI 权限、轨道支援。

跨系统测试：机器人+电子战、AI中心被毁+分布式节点、桥梁破坏+寻路、断电+算力、网络重连+AI。

完整对局测试：AI 对 AI、真人对 AI、多人同步、长时间运行。

## 故障注入

主动测试断电、AI中心被毁、数据中心失效、卫星链路断开、重干扰、桥梁被炸、网络延迟/断线。系统应“可解释降级”，不能连锁崩溃。

## AI 对战农场

持续运行国家×国家×地图×科技路线×AI风格矩阵。每日根据算力运行数千至数万局，记录胜率、对局时间、科技选择、单位成本交换、地图偏差、投降时间。

## 平衡闭环

发现 55%+ 或 45%- 异常 → 按段位/地图/时间段/科技/单位定位 → 提出局部修正 → 再模拟 → 人工试玩确认。AI 不可为追求 50% 把特色调平。

## 地图 QA

自动检测出生资源距离、战略点距离、路线长度、可建面积、桥梁/通道瓶颈和不同阵营抵达时间。美术完成后必须重新平衡，不能认为灰盒平衡会自然保留。

## 完成定义

任何系统交付必须有正常路径、极端路径、错误路径、性能、确定性和文档验证。
