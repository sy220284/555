# 内容生产管线

## 单位

玩法定位 → 白盒配置/占位模型 → 数值与反制测试 → 概念 → 模型/材质 → 动画 → 特效/音频 → 可读性测试 → 最终平衡。

禁止“先做漂亮模型，再决定单位用来干嘛”。

## 建筑

功能与依赖 → 占地/建造关系 → 白盒 → 正常视距可读性 → 概念与模型 → 破坏阶段 → 特效/音效 → 平衡。

## 地图

灰盒路线/资源/战略设施 → AI 批量测试 → 出生平衡 → 美术 → 破坏/天气 → 再次 AI 与真人验证 → 排位门禁。

16 张地图从一开始全部建灰盒骨架，互不等待。

## 战役

24 关全部先建立可通关灰盒：目标、触发器、AI、增援、胜负、占位对白。剧情/配音/过场后续替换，不阻塞关卡逻辑。每关必须至少突出一个主要玩法，不连续复制“造基地→摧毁基地”。

## 美术资产

独立资产流水线可并行：概念 → 高模 → 游戏模型 → 材质 → 层级模型 → 动画/挂点 → 特效 → 技术验收。自动检查三角形、材质、贴图、碰撞、LOD、命名。

## 机器人复用

建立四足、人形、多足、履带无人平台等基础骨架，国家通过外形、模块和动作风格区分，避免每个机器人重复整套动画。

## 占位原则

任何正式资产缺失都使用明显占位，不得阻塞程序、数值、地图或战役测试。
