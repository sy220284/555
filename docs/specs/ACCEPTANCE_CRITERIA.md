# 验收与完成标准

## 项目级

- 主分支可编译、启动、加载地图并运行完整基础对局。
- 标准 1v1 在目标硬件达到性能预算。
- 多人确定性、录像和重连可复现。
- 现代模式不存在必须靠调试命令才能完成的核心循环。

## 系统级

每个系统必须具备：正常流程、边界流程、故障降级、自动测试、性能基准、确定性验证（如相关）、文档、AI/玩家使用路径、反制或失败机制。

## 单位/建筑

必须可生产/建造、移动或工作、执行主要能力、受损/死亡/摧毁、正确计费、正确占容量、被 AI 使用、网络/录像一致、正常视距可识别、有明确反制。

## AI 指挥

必须严格遵守授权区域、预算、风险和禁止事项；玩家可立即接管；AI 中心损毁后按规则降级；不得获得作弊属性或视野。

## 机器人

算力/能源/容量/资源生效；断联按自主等级降级；电子战不能一键全灭；维修和补充可工作；有人单位仍具备不可替代价值。

## 地图

出生、资源、战略设施、可建区域、通道和主要抵达时间通过自动检测；真人/AI 多轮对局无明显结构性出生优势。

## 战役

从开场到胜/败完整可通；存档/加载关键节点正常；目标提示清楚；剧情触发可重复；不依赖一次性时序巧合。

## 文档

接口和规则变更必须同步对应文档。若实现与文档不一致，功能不得标记正式完成。

## 完成含义

“代码写完”不等于完成；代码 + 数据 + 集成 + 测试 + 确定性 + 性能 + 文档 + 可玩性验收全部通过才是完成。
