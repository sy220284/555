# 空军、海军与轨道执行规则

## 1. 空军基本模型

飞机不是普通地面单位换皮。每架飞机属于某机场/航母的维护容量，执行`READY -> TAXI/LAUNCH -> MISSION -> EGRESS -> RETURN -> TURNAROUND`循环。

玩家下达任务区/目标，默认不要求逐架手动返航。高级玩家可中止/改航。

## 2. 空战发现与锁定

发现由Radar/IRST/Visual/DataLink综合。隐身降低被探测概率和可靠跟踪距离，不提供永久不可见。

空空攻击必须达到Confirmed，远距武器推荐Locked。失去Locked后已发射武器按自身导引能力继续，命中率降低。

AEW提供高范围发现但自身高价值、低生存；电子战机降低敌Radar/Comms质量。

## 3. 航空弹药与整备

普通战斗机标准4个“任务弹药点”，远程空空/重型对地各消耗1—2点。打完后自动返场。整备时间见经济规格。

机场被毁后空中飞机可寻找盟友/临时机场；无可用机场时进入低油量倒计时并最终损失，避免永久盘旋。

## 4. 防空层级

SHORAD对无人/直升机/低空；MRAD对战斗机；LRAD对高价值空中目标；ABM对弹道/高速战略目标。

单一防空不能同时最高效处理所有威胁。空军可通过EW、诱饵、地形/低空、远程武器压制防空，但不能无视完整防空网。

## 5. 海军模型

海面分为浅水/深水/港区/狭水道。大型舰艇不能通过部分浅水与狭窄航道。潜艇在深水隐蔽更高，浅水更易被探测。

海军同样使用情报等级；远程反舰武器要求Confirmed/Locked目标。失去跟踪会显著降低超远程命中。

## 6. 航母

航母核心价值是机位、维修、预警/无人航空支撑，不作为最高输出炮舰。航母本体拥有近防与有限防空，但面对完整反舰攻击必须依靠编队护航。

标准航母维护：8架有人战机等效机位；可按规则替换为无人机/预警机组合。

## 7. 潜艇与反潜

潜艇拥有`AcousticSignature`。高速航行/发射武器增加签名；静默降低速度但提高隐蔽。

反潜来源：舰载声呐、拖曳阵、直升机、无人艇/无人潜航器、固定传感器。被发现不等同永久锁定。

## 8. 无人海战

USV承担侦察/诱饵/近海攻击；UUV承担深海侦察/反潜/渗透。高级UUV受算力与通信约束，但必须具备离线任务能力，不能因水下失联直接停机。

## 9. 海军补给

远离港口后依赖补给舰恢复导弹备弹与维修。断供不影响基础航行/舰炮，但高端导弹无法补充。

## 10. 轨道层定位

轨道层只做战略支援，不允许直接框选几十颗卫星战术移动。轨道资产自动按预定轨道/任务窗口运行，玩家选择部署、任务优先级、干扰、保护、补充。

## 11. 卫星类型

侦察：周期性大范围图像/雷达刷新。
通信：提高跨战区数据共享与AI链路。
导航：提高精确武器/无人导航质量。
预警：提前发现战略导弹/高空目标。
电子侦察：发现雷达/通信发射源。
检查：靠近、识别异常卫星。
维修：恢复/延寿部分己方资产。
电子战：对指定区域轨道链路施压。
拦截器：高成本有限反太空能力。

## 12. 轨道覆盖

卫星不是永久全图视野。每个轨道能力拥有`coverage_window`与`refresh_interval`。星座科技通过更多资产缩短刷新，而不是让单星无视轨道规律。

## 13. 反太空

手段：地面反卫星、激光致盲、电子干扰、网络攻击、轨道接近、攻击地面测控站。

直接动能摧毁会生成`DebrisRisk`，使双方同轨道资产故障概率上升一段时间。排位中DebrisRisk有明确上限，避免随机雪崩。

## 14. 失去卫星后的降级

失去导航：精确武器受影响，但惯导/地形匹配/量子导航提供保底。
失去通信：跨战区共享变慢，本地链路保持。
失去侦察：目标刷新变慢，地面/空中传感器仍有效。

任何卫星损失都不得让地面军队完全失去控制。

## 15. AI自动管理

玩家可选择轨道自动模式：AI按“侦察优先/通信优先/防御优先/平衡”分配轨道任务。AI不得自动使用动能反卫星武器，除非玩家授权战略攻击。

## 16. 性能

空军高层航线5Hz更新、局部机动10—20Hz；海军高层路径1—2Hz；轨道战略状态1Hz即可。远离镜头的航空/海军动画与传感器可降频，但确定性状态不省略。

## 17. 验收

必须验证：机场满载、机场被毁改降、无机场返航失败、AEW被击落后的情报降级、海军补给断裂、潜艇静默/暴露、UUV断联自主、卫星过顶刷新、轨道干扰、测控站被毁、碎片风险、AI自动轨道管理。
