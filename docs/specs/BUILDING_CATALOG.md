# 全建筑规格目录

## 1. 统一规则

字段：`CostIndustrial/Strategic`、`BuildTime`、`HP`、`Armor`、`Footprint`、`PowerDelta`、`ComputeDelta`、`CommandDelta`、`Tier`、`Prerequisites`。

建筑被摧毁后允许留下废墟；废墟默认阻挡大型车辆，工程单位可清理。核心节点损失只削弱对应体系，不允许单点全军停机。

## 4. 未来科技建筑

`BLD_FUTURE_PRISM`：T5，6500/1200，HP1800，功耗80，基础射程1100；可与最多3座邻近棱镜塔协同，每条能量链增加20%伤害，累计上限60%；对无人/轻装优秀，对重装需要持续照射。

`BLD_FUTURE_TESLA`：T5，6200/1100，HP2200，功耗75，射程900；动能伤害一般，电磁/系统伤害高；对具高电磁防护的重装单位效率下降。

`BLD_FUTURE_IRONCURTAIN`：T5，15000/2800，HP3000，功耗120；战略能力建筑，提供区域主动防护，不提供绝对无敌。

`BLD_YURI_NEURAL_TOWER`：T4，5200/900，HP1800，功耗55，Compute+40；对人员与低自主机器施加认知/算法压力，可被隔离网络、人工接管和系统抗性反制。

## 6. 电力规则

`PowerAvailable >= PowerDemand`：正常。

80%—99%：生产/维修速度 -10%。

60%—79%：生产/维修 -25%，远程雷达刷新 -20%。

<60%：关闭低优先级防御/计算任务，AI自动按玩家预设优先级卸载负荷。

关键防御不得因瞬间欠电直接永久失效，恢复电力后10s内重启。

## 7. 建造规则

基础建造速度为1.0；多个工程单位协助采用 `1 + 0.35*sqrt(n)`，最高2.4倍，避免工程单位无限叠加。

建筑维修每秒恢复最大HP的1%，工业资源消耗为该建筑原价的0.45%/秒；战斗中受到伤害后5秒才可进入满速维修。

## 8. 摧毁/降级

- Command摧毁：不能新增主基地级建筑，但已有单位继续作战。
- DataCenter摧毁：目标共享延迟+25%。
- AICommand摧毁：授权部队按自主等级降级，本地命令仍可执行。
- Compute摧毁：降低最大算力，可能触发过载。
- SatCom摧毁：轨道与跨战区链路效率降低，不影响本地无线/有线网络。
- Logistics摧毁：前线补给恢复速度显著下降。

所有降级必须可观察、可恢复、可反制。
