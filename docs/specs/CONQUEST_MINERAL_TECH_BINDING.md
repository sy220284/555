# 征服模式矿产—科技绑定执行规格

本文件仅适用于 `MODE_CONQUEST` / `RULESET_CONQUEST_STANDARD`，用于把关键矿产争夺直接转化为科技路线争夺。

本文件是 `MINERAL_RESOURCE_SYSTEM.md` 在征服模式下的专项覆盖规则：其他标准模式继续保持“矿产主要提供资源与产业优势、不硬锁核心科技”；征服模式允许特定T3/T4/T5科技使用材料访问标签作为前置。

## 1. 设计目标

- 让稀土、锂镍钴、高性能合金、核燃料等矿区成为真正值得争夺的战略目标；
- 让玩家通过控制不同矿区形成不同科技路线；
- 允许绕开某种资源，改走另一套军事体系；
- 允许通过破坏矿区、精炼厂和物流暂时压制敌方高级体系；
- 不使用比赛时间解锁科技；
- 不允许单个矿点永久锁死整局核心玩法。

## 2. 绑定原则

科技分为三类。

### 2.1 基础科技

T1、绝大多数T2以及基础生产、防御、侦察科技不得绑定具体矿种。

任何玩家失去战略矿后，仍必须拥有完整基础作战能力。

### 2.2 战略材料科技

部分T3/T4科技需要对应的 `MaterialAccessTag`。

获得条件必须同时满足：

- 稳定控制对应矿区；
- 矿区连接到己方物流网络；
- 对应采掘/精炼/加工节点处于运行状态；
- 或拥有规则允许的等价替代来源。

满足后获得材料访问标签，而不是把矿石做成新的主界面货币。

### 2.3 终局/战略科技

少量T4/T5高价值科技允许需要两种材料标签组合，但不得形成唯一强制路线。

任何一条材料路线都必须至少存在一种可竞争的替代战术体系。

## 3. 材料标签

沿用矿产系统现有材料访问标签：

- `MAT_RARE_EARTH_ACCESS`：稀土/高端电子材料；
- `MAT_BATTERY_ACCESS`：锂、镍、钴等高密度储能材料；
- `MAT_ALLOY_ACCESS`：钨、钛、铬、钼等高性能合金；
- `MAT_NUCLEAR_ACCESS`：铀、钍等核燃料；
- `MIN_MIXED_STRATEGIC` 在征服地图中可按地图规则提供一种指定材料的等价替代访问，但必须在赛前地图信息中公开。

基础金属不作为高阶科技锁，主要承担工业资源供给。

## 4. 科技绑定方向

### 稀土 `MAT_RARE_EARTH_ACCESS`

主要绑定：

- 高级有源相控阵雷达；
- 高级电子战与反电子战；
- 高精度制导升级；
- AI传感融合；
- 先进无人机传感器；
- 高级数据链；
- 部分高端反导/目标识别系统。

不得绑定基础雷达、基础防空、基础无人机和基础数据链。

### 电池材料 `MAT_BATTERY_ACCESS`

主要绑定：

- 高自主机器人平台；
- 长航时无人机；
- 大规模无人蜂群；
- 高功率定向能储能模块；
- 先进移动储能/边缘算力车；
- 高密度电驱推进升级。

不得绑定普通车辆、基础机器人和普通短程无人机。

### 高性能合金 `MAT_ALLOY_ACCESS`

主要绑定：

- 顶级复合装甲；
- 高超音速武器部件；
- 高级航空发动机/耐热结构；
- 重型远程火炮升级；
- 高端导弹与拦截弹结构升级；
- 部分重型机器人装甲模块。

不得绑定基础坦克、基础火炮和基础航空。

### 核燃料 `MAT_NUCLEAR_ACCESS`

主要绑定：

- 核动力舰艇高级模块；
- 高密度战略能源设施；
- 核战略武器链；
- 部分轨道/高能战略能力的能源前置。

不得绑定常规发电、普通海军和普通轨道侦察。

## 5. 科技状态

受绑定科技存在：

- `LOCKED_MATERIAL`：科技前置已满足，但缺材料访问；
- `RESEARCHABLE`：材料访问、建筑和前置全部满足；
- `RESEARCHED`：已研究完成。

材料访问只决定对应高级能力是否可研究/制造/持续供应，不改变基础科技规则。

## 6. 已研究科技失去矿产后的处理

失去材料访问不会让科技“遗忘”，也不会让现役单位瞬间失效。

### 6.1 制造依赖

适用于高级装甲、新型高端导弹、先进机器人等：

- 现役单位继续使用；
- 新生产对应高阶单位/模块暂停；
- 库存中的高级弹药可以继续消耗；
- 恢复材料访问后重新生产。

### 6.2 持续运行依赖

适用于大规模无人蜂群、高功率定向能、部分高算力传感融合等：

- 失去材料供应后不会立即关闭；
- 使用 `StrategicMaterialReserve` 作为供应缓冲；
- 储备进入低位时界面显示“材料紧张”；
- 储备耗尽后进入预定义降级模式；
- 恢复物流后逐步恢复正常。

这使抢矿产生战略压力，又避免一次偷点直接让整支军队报废。

## 7. 战略材料储备

征服模式维护后台 `StrategicMaterialReserve`，不增加四五条需要玩家逐项微操的货币栏。

玩家界面只显示各材料供应状态：

- `充足`
- `紧张`
- `断供`

矿区、加工节点和物流连接共同决定补充状态。

储备量由真实供应与消耗决定，不根据比赛经过时间自动增减。

## 8. 争夺链条

玩家不必只占矿本身，可以攻击整条产业链：

`矿体 → 采掘站 → 精炼/加工 → 电力 → 道路/铁路/港口 → 科技/生产设施`

任何关键环节被切断都可以让材料访问进入中断或储备消耗状态。

因此策略包括：

- 正面夺矿；
- 空袭精炼厂；
- 特种部队破坏电力；
- 炸桥/切铁路；
- 海军封锁港口；
- 电子战干扰自动化节点；
- 防守自己的材料供应线。

## 9. 地图公平

征服排位地图必须满足：

- 任意单一具体矿种不能成为唯一赢法；
- 每队到首个同类型关键矿的等价抵达成本差小于10%；
- 至少存在两种高级科技路线可以不依赖同一种矿；
- 空间不足的地图可以使用 `MIN_MIXED_STRATEGIC` 作为公开的等价替代；
- 核燃料矿不得放在单方天然安全区形成不可争夺优势；
- 关键矿区附近必须存在至少两种争夺路径，或存在可被远程、空中、特种、机动作战影响的外围设施；
- 同类型关键矿不能全部集中在同一方天然推进轴线上。

## 10. 科技路线与玩家策略

### 信息体系

稀土优先 → 雷达/电子战/制导/传感融合 → 通过信息优势扩大交换比。

### 无人体系

电池材料优先 → 高自主机器人/长航时无人/蜂群 → 通过低人员成本和控制面扩大取得优势。

### 重装与远火体系

高性能合金优先 → 重装甲/航空/远程火力/高速武器 → 强化正面突破和远距打击。

### 战略威慑体系

核燃料优先 → 战略能源/核动力/高能战略能力 → 投资大、暴露高、终局能力强。

玩家也可以主动放弃某种关键矿，以成熟低阶部队、经济优势、地图控制、兵种克制或破坏敌方供应链取胜。

## 11. AI要求

AI必须理解：

- 当前科技路线缺什么材料；
- 敌方控制某矿后可能解锁什么体系；
- 是夺矿、封锁物流、炸精炼厂、破坏电力还是改走替代路线更划算；
- 不因为某矿“科技价值高”就无脑投入全部主力；
- 材料断供后能调整生产队列和编制，而不是持续排队不可制造单位；
- 能利用假攻、空袭、特种渗透和远程火力制造材料供应中断。

## 12. UI与情报

科技树必须直接显示缺失前置，例如：

`缺少：稀土材料访问`

地图矿区显示：

- 矿种；
- 当前控制；
- 是否连接己方物流；
- 是否正在供给；
- 已知情况下敌方可能受益的科技类别。

不能要求玩家打开多个二级面板才能理解为何科技被锁。

## 13. 平衡门禁

- 基础战斗体系不得被任何具体矿种锁死；
- 材料绑定科技主要集中于T3以上；
- 同一种材料不能同时成为经济最强、科技最强、地图最安全的资源；
- 单一材料路线长期选择率超过65%或胜率明显异常，必须调查；
- 失矿后的降级必须给玩家反应与反攻空间；
- 不设置落后方免费材料补贴；
- 不使用比赛时间自动解锁替代材料。

## 14. 自动验收

至少验证：

- 缺对应材料时绑定科技正确处于 `LOCKED_MATERIAL`；
- 获得稳定矿区+加工+物流后正确进入 `RESEARCHABLE`；
- 已研究科技不会因短暂失矿被删除；
- 制造依赖与持续运行依赖分别按规则处理；
- 切断物流、断电、摧毁加工节点和失去矿区均能正确改变材料供应状态；
- 恢复供应后状态可正确恢复；
- 至少四条主要战略材料路线不存在单一路线长期统治；
- 镜像地图关键矿抵达成本符合公平阈值；
- AI能正确识别材料价值和替代路线；
- 任何材料/科技解锁逻辑均不得读取 `elapsed_match_time`。
