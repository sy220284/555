# 经济、资源、容量与补给精确规则

## 1. 资源

主界面长期显示：工业资源、战略资源、电力、指挥容量、算力。

战场数据为后台科技资源，只在科技/情报界面显示。

## 2. 初始值

标准1v1：工业12000、战略2000、战场数据0、指挥上限300、基础算力20、基础电力余量100。

快速模式：工业15000、战略2500；科技时间×0.8。

战区模式：工业12000、战略2000，但补给与轨道完整启用。

## 3. 资源节点

### 工业矿区
标准节点容量60000工业资源；单采集组基础效率900/分钟。最多2组同时工作，第二组效率80%。

### 战略资源点
标准容量12000；基础效率180/分钟；最多2组，第二组效率70%。

### 工业区/港口
占领后提供被动收入：工业250/分钟；大型港口350/分钟。

### 数据中心
占领后提供战场数据30/分钟，并增加局部情报刷新。

### 能源设施
占领后+80电力，不产生工业货币。

## 4. 收入目标

前期5—10分钟：900—1200工业/分钟。
中期10—25分钟：2000—3200/分钟。
后期25分钟后：4000—5500/分钟。

战略资源通常为工业收入的8%—14%，不允许无限堆高端单位。

## 5. 建造支付

生产开始时锁定总价，但按进度线性实际扣除；取消返还未消耗部分100%，已消耗部分不返还。这样避免取消生产套利。

建造速度：`EffectiveBuildRate = BaseRate * FactoryModifier * PowerModifier * CountryModifier * QueueModifier`。

同一工厂多队列不叠加；增加产能必须建设更多工厂或国家专属自动化升级。

## 6. 维修

车辆/建筑维修消耗工业资源；机器人高级模块额外消耗少量战略资源。

维修成本总上限：从1HP修至满HP约等于原工业造价的35%；高级电子/机器人额外支付原战略造价的20%。

维修速率：基地保障半径内最大HP 2%/秒；前线保障1%/秒；随队维修0.5%/秒。受到伤害后5秒内维修效率减半。

## 7. 回收

己方残骸由工程/维修单位回收可返还原工业成本10%—25%，由残骸完整度决定；敌方残骸最多15%。战略资源不直接回收，特殊科技除外。

## 8. 指挥容量

基础上限300；战区指挥中心+80；高级数据/AI节点可通过科技额外提供10—30；标准排位硬上限500。

超出容量禁止新单位完成出厂，但已在队列中的单位暂停在99%。不会自动摧毁现有单位。

典型占用：步兵1、小机器人1、轻车2、无人战车3、坦克4、火炮4、高级机器人4—5、战机6、母平台8、驱逐舰14、航母20。

## 9. 算力

最大算力=`基础20 + 数据中心40*N + AI中心100*N + 战略计算250*N + 边缘节点40*N + 国家修正`。

使用率=`当前需求/最大算力`。

- <=100%：1.0效率。
- 100—125%：AI决策周期×1.15，目标共享延迟+10%。
- 125—150%：周期×1.35，共享延迟+25%，低优先A4降为A3。
- >150%：周期×1.7，共享延迟+45%，按玩家优先级把低优先自主单位逐步降级，直到需求<=150%。

算力过载不降低普通坦克基础射击伤害。

## 10. 电力

电力不是货币。若供给不足，按玩家可配置优先级卸载：装饰/低优先生产 → 高级计算 → 非关键防御 → 其他。

电力系数：>=100%=1.0；80—99%=0.9；60—79%=0.75；<60%=0.5并进入负荷切除。

基础移动、手动武器和主基地最低生命支持不因欠电完全关闭。

## 11. 补给

单位只有三档：充足、不足、断供。

每个单位有`SupplyUse`；保障节点提供`SupplyCapacity`与半径。系统每5秒重新分配一次，不做每发炮弹物流模拟。

- 充足：100%维修/弹药/技能恢复。
- 不足：高级弹药补充×0.6，维修×0.7，技能冷却×1.15。
- 断供：只使用现存高级弹药；维修×0.25；部分战略技能停用；基础移动和主炮仍可使用。

标准保障中心容量120；前线保障40；补给舰80；支援机器人小队5。

## 12. 航空保障

每个标准空军机位对应1架有人战机或2架轻无人航空器的维护容量。超出机位仍可紧急降落，但补弹/维修速度降至40%。

战机返场后基础整备：普通战机18秒、隐身打击24秒、轰炸机35秒、无人战机14秒；国家科技可修正。

## 13. 海军保障

海军远离港口时依赖补给舰。无补给不影响航行，但导弹备弹恢复停止，维修降至20%。

## 14. 战场数据

获得方式：首次确认敌单位+1—3；锁定高价值目标+5；控制数据中心30/分钟；完成任务/战略侦察由模式脚本奖励。

同一普通单位重复发现不重复刷取数据；按对象/时间窗口去重。

## 15. 经济领先抑制

不设置强制追赶补贴。地图通过边缘资源、战略设施和暴露的扩张点形成自然风险。领先玩家若扩张过度，需要更多防御/后勤投入。

## 16. 投降与资源销毁

多人投降后，未使用资源不转给队友；团队模式可按规则将未完成生产取消。禁止通过退出游戏向盟友转移资源套利。

## 17. 数值验收

标准AI对局需满足：5分钟内首个外部争夺点可达；5—12分钟可发生有效主战；12—20分钟T3常见；20—30分钟T4常见；30分钟后T5可达但不能保证所有玩家都能负担完整T5。
