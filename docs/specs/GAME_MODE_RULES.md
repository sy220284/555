# 游戏模式执行规则

本文件把 `design/03_GAMEPLAY_LOOP_MODES.md` 的五种模式转成可直接编码的规则集。模式通过稳定 `ruleset_id` 驱动，禁止在地图脚本中复制一套胜负逻辑。

## 1. 稳定 ID

- `MODE_ANNIHILATION`：歼灭
- `MODE_CONQUEST`：征服
- `MODE_FRONTLINE`：前线
- `MODE_THEATER`：战区战争
- `MODE_QUICKWAR`：快速战争

对应默认规则集：

- `RULESET_ANNIHILATION_STANDARD`
- `RULESET_CONQUEST_STANDARD`
- `RULESET_FRONTLINE_STANDARD`
- `RULESET_THEATER_STANDARD`
- `RULESET_QUICKWAR_STANDARD`

## 2. 通用比赛生命周期

```text
LOBBY -> LOADING -> DEPLOYMENT -> LIVE -> ENDING -> RESULTS
```

- `DEPLOYMENT`：20秒，允许观察出生区和设定AI授权，不允许越出出生区攻击。
- `LIVE`：权威计时开始。
- `ENDING`：胜负条件满足后保留5秒收束窗口，冻结新增生产/科技命令，已发出的非战略弹道完成结算。
- `RESULTS`：服务器签名结果，写入录像、统计和排位服务。

## 3. 通用失败条件

玩家满足任一条件可被判定个人失败：

1. 所有可重建指挥核心被摧毁，且60秒内无法开始合法重建；
2. 主动投降；
3. 团队模式下全队投降通过；
4. 竞技比赛被服务器判定非法客户端/规则破坏并执行强制判负。

普通掉线不立即判负，按重连规则保留60秒控制权；期间玩家侧L1自动防守继续运行，禁止L3/L4自动发动战略进攻。

## 4. 歼灭 `MODE_ANNIHILATION`

目标：摧毁敌方体系并使其失去重建能力。

胜利：所有敌队同时不存在可用指挥核心，且不存在已开工、能在60秒内完成的合法指挥核心重建。

规则：

- 不需要清除地图最后一名步兵；
- 流亡单位继续存在，但失去生产/科技能力后不能无限拖局；
- 45分钟后进入“战略压力”阶段：中立资源刷新减少20%，战略设施收益+20%，促使离开龟缩区；
- 不直接给予伤害加成。

## 5. 征服 `MODE_CONQUEST`

地图定义3—7个 `VictoryZone`。

占领规则：

- 区域内只有一方存在合法占领权重时开始占领；
- 基础占领时间20秒；
- 步兵权重1.0，工程1.25，轻车0.5，重车0.25，机器人0.5；航空、远程火炮、舰外导弹不提供占领权重；
- 双方均存在占领权重时区域争夺，不增长；
- 离开后进度每秒回退5%，直到中立或原控制状态。

积分：

- 每控制一个胜利区每5秒+1分；
- 中央高价值区可由地图声明权重2；
- 标准目标分500；
- 达到目标分后必须至少保持一个胜利区30秒完成胜利确认；全部区域失守则确认暂停。

## 6. 前线 `MODE_FRONTLINE`

地图定义连续前线节点：`FrontNode[0..N]`。

规则：

- 只能争夺与己方已控制节点相邻的节点；
- 一个节点基础占领30秒；
- 占领后生成90秒前线补给加成窗口：附近己方补给恢复+20%，不增加基础伤害；
- 敌方可在窗口结束后反推；
- 控制敌方最后一层前线并保持60秒胜利；
- 主基地摧毁仍可直接触发歼灭式失败。

该模式禁止通过空降直接跳过未连通前线节点完成占领，但空降可以切后勤、侦察和破坏。

## 7. 战区战争 `MODE_THEATER`

启用：

- 完整后勤；
- 海军；
- 多战线；
- L1—L4玩家AI权限；
- 更完整轨道支援；
- 3000—5000实体扩展目标。

胜利采用“战区控制值”：

`TheaterScore = ObjectiveScore + InfrastructureScore + EnemyCollapseScore`

- 战略区域每分钟计分；
- 港口/机场/数据中心/能源等设施提供小额持续值；
- 摧毁敌核心提供一次性值，但不能单靠远程火力立即结束；
- 标准目标1000分；领先达到100分且总分>=1000时进入120秒胜利确认；若领先差缩小到<100则取消确认。

默认时长45—90分钟；超过90分钟进入加速结算：战略区积分×1.5，资源节点剩余采集效率-20%，不改变单位属性。

## 8. 快速战争 `MODE_QUICKWAR`

目标15—25分钟。

默认：

- 初始工业15000、战略2500；
- 科技研究时间×0.8；
- 后勤自动化；
- 轨道简化；
- 玩家AI仅L1/L2；
- T5仍可用，但成本不降低；
- 地图只选择快速模式认证布局。

胜利条件按地图选择歼灭或征服子规则，不建立第三套胜负算法。

## 9. 团队投降

- 1v1：玩家确认后立即投降。
- 团队：发起投票后30秒窗口；超过半数存活玩家同意即团队投降；2人队要求双方同意。
- 同一玩家60秒内只能发起一次。
- 投降资源不得转移给盟友。

## 10. 友军与联盟

标准排位：固定队伍，比赛中不能改联盟。

- 直接瞄准友军：禁止；
- 范围爆炸：默认对友军造成25%权威伤害；
- 超级武器：对友军造成50%伤害，预警明确显示；
- 维修/补给可作用盟友，消耗施放方资源；
- 自定义房允许房主规则覆盖，但必须进入 `ruleset_id/content_hash`，录像可复现。

## 11. 平局与异常

- 正式比赛不得以客户端断线决定平局；由权威服务器状态判定。
- 服务器灾难性故障且无法恢复权威快照时标记 `NO_CONTEST`，不计排位分。
- 双方同一权威tick满足最终失败条件时，按该tick开始前的胜负指标比较；仍完全相同则平局。

## 12. 验收

每个规则集必须自动覆盖：胜利、失败、同时触发、重连、投降、团队投票、占领争夺、加时/确认、友军范围伤害、AI授权限制、录像重放和服务器重启恢复。
