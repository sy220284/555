# 游戏模式执行规则

本文件把 `design/03_GAMEPLAY_LOOP_MODES.md` 和 `design/04_FREEDOM_WARFARE.md` 转成可直接编码的五种标准规则集。模式通过稳定 `ruleset_id` 驱动，禁止地图脚本复制另一套胜负逻辑。

## 1. 稳定ID

- `MODE_ANNIHILATION`：歼灭
- `MODE_CONQUEST`：征服
- `MODE_FRONTLINE`：前线
- `MODE_THEATER`：战区战争
- `MODE_QUICKWAR`：快速战争

默认规则集：

- `RULESET_ANNIHILATION_STANDARD`
- `RULESET_CONQUEST_STANDARD`
- `RULESET_FRONTLINE_STANDARD`
- `RULESET_THEATER_STANDARD`
- `RULESET_QUICKWAR_STANDARD`

## 2. 统一自由度约束

标准规则禁止使用比赛时间推动战争阶段：

- 不按分钟改变资源收益；
- 不按分钟提高胜利积分；
- 不按分钟提高伤害；
- 不按分钟开放科技；
- 不存在标准比赛时长上限；
- 不存在“超时自动进入决战”。

建造、研究、占领、维修、技能冷却、重连和投降投票等动作本身仍可使用秒数。

## 3. 通用比赛生命周期

```text
LOBBY -> LOADING -> DEPLOYMENT -> LIVE -> ENDING -> RESULTS
```

- `DEPLOYMENT`：所有客户端完成加载后进入，可观察出生区、设定编队和AI授权；所有存活玩家准备后即可进入LIVE。竞技服务可设置纯技术性的最大准备超时，但不得改变开局资源/兵力。
- `LIVE`：战争规则开始运行，不存在模式级倒计时。
- `ENDING`：服务器已确认不可逆胜负状态后冻结新的战略级命令，完成当前权威tick结算。
- `RESULTS`：服务器签名结果写入录像、统计和排位服务。

## 4. 通用战争能力

模式可使用以下状态判断玩家是否仍拥有恢复战争的真实路径：

- `CommandOperational`：存在合法指挥核心，或存在能够建立指挥核心的合法重建路径；
- `ProductionOperational`：存在可生产关键单位的链路，或存在合法恢复路径；
- `LogisticsOperational`：至少一支主要作战力量能够获得基础保障，或存在可恢复保障路径；
- `TerritoryAccess`：拥有合法建设/部署区域，或具备重新夺取建设空间的能力；
- `ObjectiveForce`：仍有单位能够执行当前模式的核心目标。

“合法恢复路径”必须同时满足：拥有相应建造/占领能力、存在可达位置、所需前置没有永久丢失。单纯“未来理论上也许能恢复”不算。

## 5. 通用失败与投降

玩家满足以下任一条件可以退出竞争：

1. 主动投降；
2. 团队投降通过；
3. 被服务器强制判负；
4. 当前模式定义的战争能力/战略目标已经不可恢复地失败。

普通掉线按重连规则处理；临时掉线不改变模式胜负逻辑。

## 6. 歼灭 `MODE_ANNIHILATION`

目标：使敌方战争组织能力不可恢复地崩溃。

### 胜利条件

敌方团队同时满足：

- 不存在可用指挥核心；
- 不存在合法指挥核心重建/夺取路径；
- 不存在能够重新建立生产体系的合法路径；
- 残余部队无法通过占领/工程/盟友体系重新恢复战争能力。

不需要清除地图最后一名步兵、无人机或残骸。

### 合法打法

标准规则允许快攻、围困、断补给、打工业、斩首、海空封锁、长期消耗和前线基地反攻。不会因为比赛进行了多久而处罚防守或奖励进攻。

主基地被毁本身不自动判负；只要仍存在真实重建路径，战争继续。

## 7. 征服 `MODE_CONQUEST`

征服围绕 `ControlRegion` 和 `StrategicSite` 的实际控制，不以持续积分作为标准胜负核心。

### 区域控制状态

区域状态：`NEUTRAL, CONTESTED, CONTROLLED_UNSTABLE, CONTROLLED_STABLE`。

基础占领权重：

- 步兵1.0；
- 工程1.25；
- 轻型车辆0.5；
- 重型车辆0.25；
- 机器人0.5；
- 航空、远程火炮、区外舰载导弹不提供地面控制权重。

从中立/敌对状态转移需要完成占领作业；占领作业时间由设施/区域规格定义。区域只有在以下状态成立后才算 `CONTROLLED_STABLE`：

- 己方完成占领；
- 区域不存在足够争夺权重的敌军；
- 至少存在指挥或保障连接，或区域拥有可运行本地保障/指挥设施；
- 区域关键设施没有处于敌方控制状态。

### 战略价值

每个区域拥有 `strategic_weight`，来自工业、机场、港口、数据、能源、交通和地图位置。控制收益直接作用实际系统，不额外凭空生成胜利积分。

### 标准胜利

默认 `StrategicDominanceThreshold = 0.70`。

团队满足以下全部条件时赢得征服胜利：

- 稳定控制的战略价值 >= 地图总可控战略价值70%；
- 对手稳定控制价值 <=20%；
- 己方至少一个指挥网络与大部分已控区域存在有效连接；
- 对手不存在立即可恢复大面积控制的封闭包围区判定错误。

地图可以在 `ruleset` 中把阈值配置为0.65—0.75，但不能加入随时间增长的占领倍率。

歼灭式战争能力崩溃同样可以结束征服局。

## 8. 前线 `MODE_FRONTLINE`

前线不使用固定 `FrontNode[0..N]`。

地图提供区域邻接图；运行时根据稳定控制关系生成：

`FrontEdge = FriendlyControlledRegion <-> EnemyOrContestedRegion`

### 允许的推进方式

- 正面突破；
- 多轴推进；
- 侧翼包抄；
- 两栖登陆；
- 空降建立破袭区/空头堡；
- 绕过坚固城市；
- 切断桥梁和交通；
- 包围后迫使区域失去补给；
- 在敌后建立新的合法保障节点后形成新前线。

空降部队可以在敌后作战，但如果没有本地保障/指挥或与己方网络建立合法连接，不能仅凭少量空降兵把敌方核心区域判为稳定控制。

### 标准胜利

每个队伍拥有一个或多个 `HomeCoreRegion`。

赢得前线战争需要满足任一：

1. 己方对敌方全部 `HomeCoreRegion` 达成稳定控制，并至少有一条合法指挥/保障连接到其中；
2. 敌方触发不可恢复的战争能力崩溃。

没有固定推进顺序、没有占领后限时增益窗口、没有按时间自动加强进攻方。

## 9. 战区战争 `MODE_THEATER`

启用：

- 完整后勤；
- 海军；
- 多战线；
- L1—L4玩家AI权限；
- 完整度更高的轨道支援；
- 3000—5000实体扩展目标。

战区战争不使用持续积分和比赛时长作为标准结束条件。

### 五大战区支柱

- `TheaterCommand`：战区指挥与数据网络；
- `IndustrialBase`：能够持续补充主要军力的工业体系；
- `LogisticsNetwork`：能够连接主要战线的补给体系；
- `StrategicAccess`：港口、机场、交通、轨道/通信等跨域进入能力；
- `FieldForce`：能够执行战略目标的主要战斗力量。

### 胜利路径A：战区支配

满足全部：

- 稳定控制地图设定的多数 `TheaterCriticalRegion`；
- 控制至少一个敌方核心战区/战略枢纽；
- 己方存在连接这些区域的有效指挥和保障网络；
- 对手已经无法通过现有区域网络恢复多数关键区控制。

### 胜利路径B：战区崩溃

敌方五大战区支柱中仅剩0—1项可运行，且其余支柱不存在合法恢复路径。

这允许通过围困、工业摧毁、封锁、指挥斩首、交通切断或正面军事胜利结束战争，而不强迫所有玩家走同一种路线。

## 10. 快速战争 `MODE_QUICKWAR`

“快速”表示减少开局准备，不表示限制比赛时间。

默认：

- 初始工业15000、战略2500；
- 开局拥有基础电力、雷达和保障设施；
- T1基础科技视为已完成；
- 可由规则集预选一组通用T2基础能力作为开局可用，但国家高级分叉仍需玩家投资；
- 后勤自动化；
- 轨道简化；
- 玩家AI仅L1/L2；
- 地图使用快速战争认证布局，减少无意义长距离准备。

研究和生产时间不因“快速”标签统一乘倍率。玩家仍可选择继续扩张、科技、龟缩或长期作战。

胜利逻辑使用快速地图声明的歼灭、征服或前线子规则，不创建基于时间的新胜负算法。

## 11. 团队投降

- 1v1：玩家确认后投降；
- 团队：发起投票后使用固定投票窗口；超过半数存活玩家同意即团队投降；2人队要求双方同意；
- 投降资源不得转移给盟友；
- 投票窗口属于交互超时，不是战争节奏机制。

## 12. 友军与联盟

标准排位固定队伍，比赛中不能改联盟。

- 直接瞄准友军：禁止；
- 普通范围爆炸：默认对友军造成25%权威伤害；
- 超级武器：对友军造成50%伤害并明确预警；
- 维修/补给可作用盟友，消耗施放方资源；
- 自定义房允许覆盖，但必须进入 `ruleset_id/content_hash`。

## 13. 平局与异常

- 正式比赛不得以客户端断线决定平局；由权威服务器状态判定；
- 服务器灾难性故障且无法恢复权威快照时标记 `NO_CONTEST`；
- 双方同一权威tick同时满足不可恢复失败状态时，按该tick开始前的模式控制状态比较；仍完全相同则平局。

## 14. 自定义限时规则

自定义房可以创建限时、积分倍率、缩圈等娱乐规则，但必须：

- 使用不同 `RULESET_`；
- 不进入标准排位；
- 明确显示规则；
- 录像记录完整参数；
- 不反向修改标准模式实现。

## 15. 验收

每个标准规则集必须自动覆盖：

- 胜利/失败和同时触发；
- 重建路径存在/不存在；
- 战略区域稳定/争夺；
- 动态前线形成、分裂、包围和重新连接；
- 后勤断裂与恢复；
- 空降/登陆不会绕过稳定控制规则；
- 长时间对局不会自动触发资源、伤害、科技或积分变化；
- 投降、团队投票、重连、NO_CONTEST；
- AI授权限制；
- 录像重放和服务器恢复。
