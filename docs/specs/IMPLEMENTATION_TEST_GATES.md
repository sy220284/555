# 实现阶段自动门禁

本文件把 `TEST_MATRIX.md` 的大范围验收拆成当前可立即执行的实现门禁。任何代理不能因为总测试尚未具备就跳过当前阶段可验证内容。

## G0 数据与仓库

每个PR必须：

- `python Tools/content_validator.py` 返回0；
- JSON可解析；
- 无旧稳定ID前缀；
- 五个标准规则集存在且无时间驱动；
- 征服启用矿产—科技绑定，其他标准规则默认关闭；
- 快速战争全科技预置；
- MAP_GRAY_RANGE资源/区域/规则集引用完整。

## G1 Unity工程编译

在 Unity `6000.3.24f1` 中：

- 所有嵌入包解析成功；
- `ModernRA.Core/Simulation/Combat/Navigation/AI/IntelEW/Robotics/Network/Tests` 编译成功；
- 不存在预览/实验依赖；
- EditMode测试全绿；
- `FixedStepSimulationSystemGroup.Timestep == 1/30f`。

G1未通过前，项目状态保持 `implementation_bootstrap`。

## G2 确定性模拟

建立 `ModernRA.SimRunner` 后：

- 同一构建、种子、初始数据、命令流运行10000 tick；
- 至少重复10次，关键状态哈希完全一致；
- 无帧率/渲染依赖；
- 不加载表现、UI、音频；
- 随机数流显式编号。

## G3 首张地图

`MAP_GRAY_RANGE.map.json` 必须：

- Schema/内容验证通过；
- 双方出生区、近家工业/战略资源对称；
- 控制区域邻接有效；
- 所有资源/设施引用存在；
- 至少两条可用战略通道；
- 可生成确定性灰盒；
- 双方初始实体可合法生成。

达到这些条件后才可从 `layout_defined` 升为 `graybox_ready`。

## G4 第一经济闭环

完成基础金属采集：

`MIN_BASE_METALS -> 采矿单位/采集组 -> 合法处理点 -> I资源池`

验证：

- 容量与采速正确；
- 第二采集组递减正确；
- 采矿单位被毁后停止对应吞吐；
- 不出现资源复制/负数；
- 回放哈希一致。

## G5 移动与共享导航

- 100/500/1000单位共享路径走廊；
- 禁止每单位全图A*；
- 桥/道路版本变更只使局部缓存失效；
- 单位无永久拥堵死锁；
- 目标CPU上采集P50/P95/P99耗时。

## G6 第一战斗闭环

至少实现一种直射武器：

目标确认 -> 开火 -> 弹道/命中 -> `DamageEvent` -> 装甲解析 -> Health -> 死亡。

权威结果不能依赖VFX、Animator或PhysX刚体。

## G7 情报与战争迷雾

- 未发现目标不进入客户端完整快照；
- Detected/Classified/Confirmed/Tracked对应不同信息精度；
- 服务器是唯一真相；
- 重连不得泄露隐藏状态。

## G8 AI战斗群

- 玩家给区域/任务/风险；
- AI在授权范围内选择局部路线/目标；
- 玩家直接命令后1个权威tick内停止继续生成旧任务高层命令；
- 禁令不可绕过；
- AI不读取隐藏情报或比赛时间。

## G9 机器人/EW

覆盖 A1—A4 × 正常/弱链路/断联/算力不足/EW黑区；验证降级而非统一停机。

## G10 网络回环

单机内运行权威服务器+客户端：

- 命令意图上传；
- 服务器30Hz；
- 可见性过滤；
- 增量状态下发；
- 客户端插值；
- 内容哈希不一致拒绝加入。

## G11 第一局完整歼灭

达到 `playable` 的第一个条件：在灰原试验场完成建设/采集/生产/移动/战斗/胜败全循环，支持录像重放并由AI完成至少一场对局。

只有G0—G11全部通过，才允许把核心工程从 `implementation_bootstrap` 升为 `playable`。

## G12 征服矿产科技

在G11之后接入：

- T1/T2不受具体矿产锁定；
- T3通用绑定1—2项；T4 2—3项；T5 1—2项；
- 矿区、精炼、物流三者共同决定 `MAT_*_ACCESS`；
- 失矿不删除已研究科技；
- 制造依赖暂停新生产；持续依赖先耗材料储备再降级；
- AI能改走替代路线；
- 不出现单矿雪球成为唯一最优解。

## G13 后续模式

依次验证：动态前线 -> 快速战争满战备 -> 战区多线/大规模。每个模式必须复用既有模拟、数据和网络能力，禁止复制一套模式专用核心引擎。
