# 矿产、采集与战略材料执行规格

本文件把地图中的抽象 `I=工业资源 / S=战略资源` 下沉为可见、可争夺、可破坏的具体矿产与加工体系。

目标：保持现代战争和关键矿产真实感，同时避免把标准对局做成需要管理七八种独立货币的资源表格。

## 1. 总原则

标准模式玩家主资源栏仍只长期显示：

- 工业资源 `I`
- 战略资源 `S`
- 电力 `E`
- 指挥容量
- 算力 `C`

战场数据 `D` 继续在科技/情报界面显示。

具体矿种存在于地图、矿区、运输、加工和产业加成层，不新增一排独立货币。

因此：

`真实矿种 -> 采集/运输/加工 -> I/S资源池 + 非叠加产业标签`

矿种身份必须产生战术价值，但不能迫使玩家逐项管理铁、铜、锂、镍、钴、稀土、钨、钛、铀库存。

## 2. 稳定矿种ID

矿种使用 `MIN_` 前缀：

- `MIN_BASE_METALS`：基础金属矿，代表铁、铜、铝等大宗工业原料；
- `MIN_RARE_EARTHS`：稀土矿；
- `MIN_BATTERY_METALS`：电池金属矿，代表锂、镍、钴等；
- `MIN_HIGH_PERFORMANCE_ALLOYS`：高性能合金矿，代表钨、钛、铬、钼等；
- `MIN_NUCLEAR_FUEL`：核燃料矿，代表铀/钍等核燃料原料；
- `MIN_MIXED_STRATEGIC`：混合战略矿，用于不适合绑定单一地质矿种的地图；
- `MIN_SALVAGE_FIELD`：战场回收资源场，不是天然矿产，只作为特殊资源节点标签。

显示名称可以因地图地质背景具体化，例如“铜铝复合矿”“锂镍矿带”“重稀土矿区”，运行时仍引用上述稳定ID。

## 3. 玩家资源结算

### 3.1 基础金属矿

`MIN_BASE_METALS` 主要结算为工业资源 `I`。

标准工业矿节点沿用：

- 基础容量：60000 I等价值；
- 单采集组基础产出：900 I/分钟；
- 最多2个采集组；
- 第二组效率80%。

地图可以通过 `grade` 和 `capacity_multiplier` 调整储量/采速，但排位镜像位置必须做等价值校验。

### 3.2 战略矿

以下矿种主要结算为战略资源 `S`：

- `MIN_RARE_EARTHS`
- `MIN_BATTERY_METALS`
- `MIN_HIGH_PERFORMANCE_ALLOYS`
- `MIN_NUCLEAR_FUEL`
- `MIN_MIXED_STRATEGIC`

标准战略矿节点：

- 基础容量：12000 S等价值；
- 单采集/加工组基础产出：180 S/分钟；
- 最多2组；
- 第二组效率70%。

不同矿种不得通过隐藏倍率让同价值出生位产生明显经济差；矿种差异主要体现在产业标签和战术位置。

## 4. 矿种产业标签

控制并连接对应矿区到己方工业/物流网络后，获得一个 `MaterialAccessTag`。

标签不是独立库存，不按拥有矿点数量无限叠加。同类型标签只取最高有效来源；失去全部合法连接后标签失效。

### `MIN_BASE_METALS`

主要价值：稳定工业资源。

无额外高科技加成，防止最常见资源同时成为万能最优资源。

### `MIN_RARE_EARTHS`

标签：`MAT_RARE_EARTH_ACCESS`

产业倾向：

- 传感器；
- 雷达；
- 电子战；
- 高端制导；
- AI/计算设备。

标准效果：符合标签的单位/升级战略资源成本最多降低5%，或对应高级弹药/模块补充效率提高5%。两者由具体内容选择其一，不能双吃。

### `MIN_BATTERY_METALS`

标签：`MAT_BATTERY_ACCESS`

产业倾向：

- 无人机；
- 机器人；
- 电驱车辆；
- 储能；
- 高功率定向能辅助系统。

标准效果：相关单位/模块战略资源成本最多降低5%，或机器人/无人平台前线补能效率提高5%。

### `MIN_HIGH_PERFORMANCE_ALLOYS`

标签：`MAT_ALLOY_ACCESS`

产业倾向：

- 重装甲；
- 航空结构；
- 高速导弹；
- 高温部件；
- 先进炮管/穿甲系统。

标准效果：相关平台战略资源成本最多降低5%，或维修中的高级材料部分降低5%。不得直接提高基础伤害/装甲数值。

### `MIN_NUCLEAR_FUEL`

标签：`MAT_NUCLEAR_ACCESS`

产业倾向：

- 核能；
- 高密度能源；
- 核动力平台；
- 战略核能力（若规则集允许）。

标准效果：核相关能力战略资源成本/补充成本最多降低5%，或高级核能设施运行效率获得等价值小幅收益。

标准排位中，核能力不得因为没有该矿而完全锁死；该矿只提供效率优势。战役/自定义规则可以把它设为任务硬条件。

### `MIN_MIXED_STRATEGIC`

不提供专属产业标签，只稳定产出 `S`，用于竞技地图控制变量和资源公平。

## 5. 为什么不做七八种独立库存

标准游戏不建立：铁库存、铜库存、铝库存、锂库存、稀土库存、钨库存、铀库存等长期独立资源条。

原因：

- 会显著增加认知和界面负担；
- 阵营科技差异容易被地图矿种随机性绑死；
- 补兵时需要检查多个材料会破坏即时战略节奏；
- AI和自动化虽能代管，但玩家无法直观判断真正缺什么。

具体矿种的意义通过“地图位置 + 运输风险 + 产业标签 + I/S产出”体现。

## 6. 采矿体系

### 6.1 普通工业矿：保留红警采矿味道

`MIN_BASE_METALS` 默认允许移动采集：

`矿区 -> 采矿车/无人矿车 -> 精炼/处理设施 -> I`

要求：

- 采矿车辆是实际战场实体，可以被伏击和护送；
- 采矿车辆自动选择合法矿区和卸载点；
- 玩家可以指定优先矿区/禁用路线；
- AI负责微操排队、避障和回程，避免玩家手动点矿；
- 摧毁采矿单位只影响真实采集能力，不直接删除矿区库存。

### 6.2 战略矿：固定矿区与加工节点

战略矿默认采用：

`矿体/矿区 -> 固定采掘站 -> 选矿/精炼节点 -> 物流连接 -> S`

玩家可通过：

- 占领中立矿区；
- 建设采掘/加工设备；
- 破坏敌方矿山电力；
- 切断道路/铁路/港口；
- 摧毁加工节点；
- 夺取矿区控制权

影响产出。

这样战略矿更像一个需要保卫的产业节点，而不是另一种颜色的矿车点。

## 7. 矿区运行状态

矿区状态：

- `UNCLAIMED`
- `CLAIMED_OFFLINE`
- `OPERATING`
- `DISRUPTED`
- `DEPLETED`

`OPERATING` 必须同时满足：

- 合法控制；
- 采掘设施可用；
- 基础电力/动力可用；
- 存在到合法加工/物流节点的连接；
- 矿体仍有容量。

`DISRUPTED` 可以来自断电、加工设施损毁、运输线切断或区域争夺。

矿区不会因为比赛进行了多久而自动衰减或刷新。

## 8. 矿石品位与储量

每个矿区可定义：

- `grade`: LOW / STANDARD / HIGH
- `capacity`
- `extraction_rate_multiplier`
- `processing_profile`
- `mineral_id`

建议倍率：

- LOW：0.80
- STANDARD：1.00
- HIGH：1.20

排位地图必须按“可获得总价值 + 路径成本 + 防守成本”综合平衡，不能只看矿点数量。

## 9. 运输与物流

矿产产出必须进入己方合法经济网络。

基础工业矿可以使用采矿车直接回精炼厂；战略矿则优先使用道路/铁路/港口物流抽象，每个连接仍对应真实地图通道。

如果运输线中断：

- 矿区可继续短暂积累有限本地库存；
- 本地缓存满后停止向资源池产出；
- 恢复连接后按正常吞吐释放，不允许瞬间无限倾倒造成经济脉冲。

标准本地缓存建议为该矿区约60秒正常产量，仅用于容错，不是战争节奏计时器。

## 10. 矿区破坏与恢复

矿体本身通常不可被普通武器“炸没”，但可以攻击：

- 采矿车；
- 采掘设备；
- 精炼厂；
- 电站；
- 输电线；
- 道路/铁路/桥梁；
- 港口装卸；
- 本地数据/自动化控制节点。

修复和重建恢复产能。

战略轰炸因此可以打击产业链，而不是靠一发导弹永久删除地图资源。

## 11. 枯竭与长期战争

天然矿体具有有限容量，可以被采空。

矿体耗尽后：

- 节点进入 `DEPLETED`；
- 不会按固定时间自动刷新；
- 原设施可改造成物流、维修、储备或回收节点（地图/科技允许时）；
- 长期经济逐渐更多依赖工业区、港口、回收、贸易/后勤型设施，而不是无限矿脉。

战区和长期沙盘因此会自然从“抢矿”过渡到“争工业与交通网络”。

## 12. 战场回收

`MIN_SALVAGE_FIELD` 代表高密度残骸区。

来源：

- 地图预置废弃装备/工业废墟；
- 大规模战斗后动态形成的高密度残骸区（达到规则阈值时聚合）。

主要产出工业资源 `I`，极少量高级残骸可以按照 `ECONOMY_FORMULAS.md` 的回收规则返还战略价值。

回收速度必须明显低于稳定矿山/工业设施，定位为补充和战后利用，不成为无限循环经济。

## 13. 各模式矿产配置

### 歼灭

- 近家：以 `MIN_BASE_METALS` 为主；
- 近家可有一个低/标准价值战略矿；
- 更丰富的稀土、电池金属、高性能合金放在外部争夺区；
- 高价值核燃料矿默认不放在单一不可替代路线。

目的：基础经济可生存，高科技矿产鼓励扩张。

### 征服

- 多数战略矿必须位于 `ControlRegion` 内或与其物流网络绑定；
- 70%—80%高价值经济位于安全出生区之外；
- 不同区域可以形成“工业区 / 稀土区 / 电池材料区 / 合金区”等明确战略身份。

目的：玩家争夺的是功能不同的地区，而非若干同质矿点。

### 前线

- 后方已有基础工业供应；
- 前线附近矿产更多影响补损能力和高级装备持续生产；
- 重要矿区必须至少有两种可争夺/破袭方式，避免唯一山口锁死全部战略材料。

目的：矿产是战役纵深目标，不要求玩家在接触线上手动经营采矿车。

### 战区战争

- 采用分布式大型矿区、工业基地、港口和交通网络；
- 不同战区可以形成不同资源专长；
- 单一矿区不能决定整个战区所有高科技可用性；
- 控制多个互补矿区可以降低长期战略资源压力，但不形成不可逆资源垄断。

### 快速战争

- 开局已有满科技与成熟基地，但地图矿产仍决定长期补损和高端单位持续生产；
- 初始资源储备只保证改编/补损，不代表无限战略材料；
- 战略矿争夺依然有价值，尤其是全体系高损耗战争下的长期持续能力。

## 14. 地图公平

排位图对矿产执行以下门禁：

- 对称出生的基础工业矿总等价值差 <=3%；
- 可达战略矿总等价值差 <=3%；
- 同类产业标签的最短获取成本必须近似对称，或双方提供等价值不同标签组合；
- 不允许一个出生点天然同时控制稀土、电池、合金、核燃料全部优势；
- 核心科技不得被唯一矿种硬锁；
- 矿区必须考虑路径、地形、防守成本和物流脆弱性，不能只比较容量。

## 15. 地图数据字段

`resource_nodes[]` 增加：

`node_id, resource_class, mineral_id, grade, position, capacity, base_income_rate, extraction_slots, processing_profile, local_buffer, control_region_id, logistics_links, material_access_tag`

其中：

- `resource_class`: `INDUSTRIAL / STRATEGIC / SALVAGE`
- `mineral_id`: `MIN_*`
- `material_access_tag`: 可为空

老地图仅有 `I/S` 时，迁移规则：

- `I -> MIN_BASE_METALS`
- `S -> MIN_MIXED_STRATEGIC`

之后再由关卡设计逐图替换成具体战略矿种。

## 16. 自动测试

必须验证：

- 所有 `MIN_*` 合法注册；
- 矿区容量不会负数；
- 同一产出不会重复进入资源池；
- 断物流后缓存行为正确；
- 失去唯一材料标签不会删除玩家已研究科技；
- 同类材料标签不叠加成指数收益；
- 排位双方资源等价值和标签获取成本通过门禁；
- 战略矿被摧毁的是设施/物流，不是矿体数据异常删除；
- 资源产量不读取比赛经过时间；
- 枯竭节点不会自动定时刷新；
- 存档/录像/重连保持矿区容量、状态和本地缓存一致。
