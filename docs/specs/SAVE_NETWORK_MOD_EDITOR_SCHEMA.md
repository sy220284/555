# 存档、网络、录像、模组与编辑器数据规格

## 1. 版本字段

所有持久数据必须包含：
`format_version`、`game_version`、`content_hash`、`map_id`、`ruleset_id`、`timestamp_utc`、`determinism_seed`。

禁止仅依赖文件名判断版本。

## 2. 存档结构

逻辑结构：

```text
SaveRoot
├─ Header
├─ MatchRules
├─ DeterministicState
│  ├─ Entities
│  ├─ Resources
│  ├─ Tech
│  ├─ AIState
│  ├─ IntelFog
│  ├─ EWState
│  ├─ Logistics
│  ├─ Orbital
│  └─ MissionScript
├─ CommandHistoryTail
└─ CosmeticState(optional)
```

必须保存：单位稳定ID/实例ID、位置/朝向、HP、弹药抽象状态、任务、战斗群、AI授权区/预算/姿态、算力、电力、科技分支、资源、补给、情报最后已知、假目标、网络战压力、轨道资产、天气、任务脚本变量。

纯视觉粒子无需保存，加载后重建。

## 3. 实例ID

运行期实体ID使用64位无符号整数；高16位可保留世界/分区，低48位为递增或确定性分配。回放/网络中实例ID不得复用，死亡实体保留墓碑索引至安全清理点。

## 4. 存档迁移

只保证最近两个主版本直接迁移。迁移器必须是纯数据变换，不运行完整游戏逻辑。无法迁移时给出明确版本错误，禁止静默丢字段。

## 5. 录像

录像不保存每帧全状态，保存：初始快照、随机种子、规则集、内容哈希、所有玩家命令、AI高层决策事件、周期校验哈希。

默认每30秒写一次状态校验点；长录像可每5分钟附带压缩快照用于快速拖动。

## 6. 网络同步

采用确定性指令同步。

客户端发送：`player_id, tick, command_type, payload, sequence, checksum`。

服务器验证权限/范围/资源后广播。正常单位位置不逐帧上传。

关键命令：选择/移动/攻击/生产/科技/AI区域授权/战略能力/队列/取消/编队/外交模式指令。

## 7. 输入延迟

标准线上逻辑输入缓冲默认2—4 tick，根据网络自动调整。服务器不得通过改变模拟速度来掩盖单个玩家高延迟；出现严重丢包时客户端进入预测等待/重连流程。

## 8. 状态哈希

每120 tick生成确定性哈希，覆盖：实体核心状态、资源、科技、AI任务、随机流位置。视觉数据不参与。

哈希不一致：先记录诊断快照；连续2次不一致则触发重同步或终止竞技比赛并保存证据。

## 9. 断线重连

服务器保留周期快照+之后命令流。客户端重连：获取最近安全快照 -> 验证内容哈希 -> 快进命令流 -> 加入当前tick。目标标准比赛60秒内允许重连。

## 10. 观战

观战者不得参与模拟命令；根据权限看到全图或选定队伍视角。竞技延迟观战默认120秒可配置。

## 11. 模组包

每个包包含：
`manifest.json`、唯一`mod_id`、语义版本、作者、依赖、兼容游戏版本、内容哈希、加载优先级、资产与数据路径。

禁止模组修改排位官方规则集。自定义房所有客户端必须内容哈希一致。

## 12. 数据模式

推荐对象数据采用可验证结构化文本/二进制中间格式。源数据可YAML/JSON，构建时编译为确定性内容包。

单位/武器/科技引用只允许稳定ID。构建器必须拒绝悬空引用、重复ID、循环科技前置、非法数值范围。

## 13. 编辑器权限

地图编辑器：地形、资源、道路、战略设施、天气、出生、AI区域、脚本触发。

单位/武器编辑器：允许自定义数据对象与新ID命名空间，不能覆盖官方ID除非创建总转换模组。

科技树编辑器：可视化前置/分叉，自动检查环。

任务编辑器：状态条件、触发、目标、增援、AI指令、剧情事件、胜败。

AI编辑器后续开放效用权重/模板，不允许注入本地任意可执行代码到联网房间。

## 14. 脚本安全

战役/模组脚本运行在沙箱：无任意文件系统、网络、进程权限；只通过游戏公开API操作实体与任务。

## 15. 官方/模组隔离

官方排位启动时只加载签名官方内容；检测到非官方影响模拟的数据包则排位禁用。纯视觉客户端模组必须经过白名单字段定义，不能修改碰撞、可见性、动画时机等竞技相关信息。

## 16. 数据热重载

开发模式允许单位/数值热重载，但进入正式对局后锁定ContentHash。中途改变配置会使录像和确定性失效，因此正式比赛禁止。

## 17. 备份与恢复

编辑器每5分钟自动保存增量草稿；用户正式保存采用临时文件+原子替换。损坏文件应保留原副本并给出恢复入口。

## 18. 验收

必须测试：跨版本迁移、5000单位存档加载、战役脚本恢复、AI授权恢复、重连、录像逐tick一致、模组依赖冲突、恶意脚本沙箱、内容哈希不一致拒绝、编辑器崩溃恢复。
