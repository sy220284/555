# 单位武器、能力与生产映射

本文件补齐 `UNIT_CATALOG.md` 与 `WEAPONS_ARMOR_MATRIX.md` 之间的直接引用关系。实现时不得根据单位名称猜武器。

## 1. 统一字段

每个真实单位定义必须显式包含：

`unit_id, production_building, prerequisites, primary_weapon, secondary_weapons, abilities, ammo_profile, veterancy_profile, audio_profile, test_profile`

无副武器/能力时写空集合，禁止字段缺失表示默认。

编队模板 `FORM_` 不生成单实体，使用：

`formation_id, members, queue_policy, total_cost_policy, unlocks, ai_usage, test_profile`

## 10. 编队模板

### `FORM_IN_HIGHLAND_BG`
成员：`UNIT_COMMON_IFV x1 + UNIT_COMMON_RIFLE x2 + UNIT_COMMON_AT x1`。

队列策略：分别在人员中心和车辆厂排队；所有成员完成后自动建立同一战斗群。总价格=成员正常总价，不打折；任一生产建筑不可用时模板暂停并提示缺失，不凭空生成。

### `FORM_PL_HEAVY_ARMOR_BG`
成员：`UNIT_COMMON_MBT x1 + UNIT_COMMON_IFV x1 + UNIT_COMMON_SHORAD x1`。

队列策略同上；总价格和时间由成员真实队列决定，不产生单个“战斗群实体”。

## 12. 老练度

统一：`VET_REGULAR`、`VET_VETERAN`、`VET_ELITE`。

经验来自有效伤害、击毁价值、占领和任务贡献，禁止攻击友军刷经验。

- Veteran：累计有效贡献 >= 1.0 × UnitValue；装填/技能恢复+5%，传感器确认+5%。
- Elite：累计有效贡献 >= 2.5 × UnitValue；累计装填/技能恢复+10%，传感器确认+10%，维修效率+10%。

不得直接增加最大HP和基础单发伤害。机器人/无人可升级，但销毁重建不继承。

## 13. 驻军

`ABL_COMMON_GARRISON` 仅步兵和明确标记小型机器人可用。

- 普通可驻建筑容量6；`BLD_DEF_BUNKER`容量8。
- 驻军获得50%远程伤害减免、20%命中稳定加成。
- 建筑进入重损时驻军每5秒承受结构冲击；坍塌时强制撤出并受30%当前生命伤害。
- 专门反驻军武器必须通过标签声明。

## 14. 友军伤害

正式默认规则以 `GAME_MODE_RULES.md` 为准：直接锁定友军禁止；普通范围爆炸25%；超级武器50%。自定义规则必须进入 `ruleset_id`。

## 15. 验收

CI必须验证：

- 每个真实 `UNIT_` 有合法生产建筑、科技前置、武器/能力、音频和AI角色；
- 每个 `FORM_` 只展开真实单位，不生成单实体；
- 所有 `WPN_`/`ABL_` 引用已注册；
- 无匿名运行时武器；
- 特殊模块切换、假目标、神经/重力等能力进入录像/存档/状态哈希。
