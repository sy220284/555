# 硬件与性能目标

## 1. 核心原则

本项目的最低硬件目标不是“能启动的低画质模式”，而是**能够正常体验游戏的标准画质基线**。

冻结原则：

- 正常画质从资产、渲染、AI、导航和数据结构层按低成本设计。
- 低配不得通过减少单位、降低AI、简化机器人、缩小地图、改变情报/电子战/命中/伤害规则来达标。
- 最低配置默认运行标准画质路径，而不是“所有效果关闭”的保底模式。
- 高端配置增加超高质量增强项，不承担“把游戏从残缺变完整”的职责。
- 如果核心体验只能在8核/32GB/12GB显存机器上成立，应优先判定为架构、算法或资产预算问题。

## 2. 最低目标机

- CPU：现代4核8线程
- 内存：16GB
- 显存：4GB
- 存储：SSD
- 分辨率：1080P
- 画质：**标准画质**
- 标准1V1：300—800活动单位完整规则
- 常规目标：60FPS
- 极高密度瞬时交战：1% Low目标约45FPS以上

最低目标机必须保持：

- 正常单位材质与可读轮廓
- 主要动态阴影
- 炮火、爆炸、导弹、拦截与机器人动画
- 正常天气表现
- 建筑损伤与坍塌阶段
- 正常战争迷雾和电子干扰反馈
- 完整AI、机器人、电子战、空军和情报规则

“最低配置”不等于“低画质”。

## 3. 主流目标机

- CPU：现代6核12线程
- 内存：16GB
- 显存：8GB
- 存储：NVMe SSD
- 1080P/1440P
- 标准高质量路径
- 800—1500活动单位
- 稳定60FPS目标

这是消费者首要优化平台和持续集成主要性能基准。

## 4. 高端体验

- CPU：8核16线程及以上
- 内存：32GB
- 显存：10—12GB+
- NVMe SSD
- 1440P/4K、高刷新率
- 大型团队1500—3000活动单位

高端增强项可包括：

- 更高精度实时全局光照
- 光线追踪
- 更远高质量阴影
- 更高体积烟雾/云采样
- 更高反射精度
- 更长残骸与弹痕生命周期
- 超高材质层

这些内容只提供额外精度，不改变基础视觉设计。

## 5. 战区与压力级

- 8—12核及以上
- 32GB+
- 12GB+显存
- 3000—5000+活动单位用于战区模式
- 10000+实体仅作为引擎、AI、导航、内存和网络压力测试

战区模式规模本身是额外玩法规模，不应反向抬高标准1V1最低配置。

## 6. 专用服务器基准

### 标准1V1—4V4

- 4—8个高性能CPU核心/线程预算
- 8—16GB内存
- 无独立GPU要求

### 大型战区

- 8—16个高性能CPU核心预算
- 16—32GB内存

服务器只承担权威模拟、AI、导航、情报、网络与存档，不运行客户端级渲染。

## 7. 开发工作站

### 程序/模拟/构建

- 12—16核以上
- 64GB内存起步
- 高速NVMe

### 美术/大型地图

- 64GB内存起步，复杂资产建议128GB
- 16GB+显存
- 高速NVMe工程盘

开发工作站仅提高编译、烘焙、资产处理效率，不能用于证明消费者性能合格。

## 8. 标准画质定义

标准画质必须在最低目标机上成立，并包含完整核心画面。

标准路径设计：

- 精简且统一的主材质体系
- 单位/建筑材质槽严格限额
- 正常纹理清晰度，不依赖4K纹理堆叠
- 主要单位与建筑动态阴影
- 烘焙/探针/轻量间接光承担基础环境照明
- 关键动态光源、爆炸和武器光效完整保留
- 正常天气、烟雾和地面反馈
- 分层几何、动画和实例化在玩家无感的情况下切换

标准画质禁止出现：

- 大量贴图糊成一片
- 核心阴影完全消失
- 爆炸/炮火大面积缺失
- 机器人动作明显降格
- 远处军队突然不可辨识
- 为省性能把战场做得空荡

## 9. 性能设计而非画质降级

性能优先通过以下技术获得：

### CPU

- 数据导向组件存储
- 热/冷数据分离
- 批量更新与向量化
- 任务系统并行
- 事件驱动
- 空间索引
- 局部脏区
- 分层AI
- 分层导航
- 路径/感知/威胁结果复用
- 对象池和零热路径分配

### GPU

- 实例化
- 遮挡剔除
- 层级细节
- 共享材质实例
- 纹理数组/图集
- 阴影缓存和代理
- 远距离动画插值
- 粒子批处理/GPU模拟
- 区域流送

### 内存

- 区域流送
- mip流送
- 资源共享
- 固定容量缓存
- 命令流录像
- 周期压缩快照

核心理念是：**同样的画面和战争，用更少的工作完成。**

## 10. 禁止用硬件档位改变的内容

- 权威模拟频率
- AI战术能力
- AI权限
- 实际单位数量
- 机器人自主等级
- 地图尺寸和可通行性
- 伤害、命中、装甲
- 雷达、情报和电子战
- 敌军数量
- 资源和生产规则
- 联机胜负逻辑

## 11. 高端增强与标准画质的关系

高端机器允许增加“采样精度”和“持续时间”，而不是添加基础机器没有的核心视觉语义。

例如：

- 标准画质已经有完整爆炸，高端增加更多二级碎片和更长烟柱。
- 标准画质已经有正常阴影，高端增加更远、更细的接触阴影。
- 标准画质已经有环境间接光，高端可增加实时全局光照精度。
- 标准画质已经有天气，高端增加更细体积采样。

因此两台机器截图的第一观感应当是“同一个完整游戏”，区别主要体现在精度，而不是一个像正式版、一个像删减版。

## 12. 性能验收

最低目标机验收：

> 4核8线程、16GB、4GB显存、SSD，在1080P标准画质下完整运行标准1V1，300—800活动单位规则一致；常规目标60FPS，极端瞬时交战仍保持可流畅操作，且画面不出现明显“低配删减感”。

主流目标机验收：

> 6核12线程、16GB、8GB显存、NVMe，在1080P/1440P标准高质量路径下稳定60FPS，800—1500活动单位完整运行。

高端机器的存在是扩展画面精度、刷新率和大型娱乐规模，不是弥补基础游戏优化不足。
