# 可观测性与持续集成

## CI 必跑

编译、单元测试、数据合法性、确定性基线、基础性能、地图结构检查、内容引用检查。主分支不允许红灯长期存在。

## 每日任务

AI 对战农场、长时运行、100/500/1000/3000 单位基准、机器人/无人机专项、断网/断电/节点失效故障注入、多平台确定性抽查。

## 指标

模拟帧耗时分布、AI/导航/感知/战斗占比、实体数、路径请求、内存、网络命令量、哈希分叉、地图胜率、国家胜率、单位成本交换。

## 性能回归

关键场景建立基准。超过允许阈值自动阻止合并或标记回归；报告必须能定位到模块和主要工作项。

## 崩溃与 BUG

每个崩溃报告绑定版本/提交/地图/模式/最近命令；可重现 BUG 优先输出最小命令流或最小存档。

## 发布

候选版本必须冻结 schema、官方内容哈希和网络协议版本，所有门禁通过后才生成发布清单。
