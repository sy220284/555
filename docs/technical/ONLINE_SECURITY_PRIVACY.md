# 在线安全、隐私与反作弊执行规格

本文件扩展 `SECURITY_ANTICHEAT.md`，面向生产环境、账号、在线服务、专用服务器和隐私数据。

## 1. 威胁模型

主要风险：

- 修改官方数据/内存；
- 注入非法命令；
- 读取战争迷雾隐藏信息；
- 伪造资源/伤害/位置；
- 重放命令；
- 伪造AI权限；
- 模组冒充官方；
- 账号盗用；
- API滥用/刷接口；
- DDoS；
- 服务器凭据泄露；
- 构建供应链污染；
- 过量收集玩家隐私数据。

## 2. 权威边界

专用服务器是资源、科技、单位真实状态、伤害、AI、战争迷雾和胜负的唯一权威。

客户端只提交意图，不提交权威结果。

未侦察真实敌军、潜艇、隐身和假目标真相不发送给无权限客户端，因此不再依赖“客户端持有完整世界再做混淆”的旧方案。

## 3. 会话与认证

- 优先平台账号/OAuth类授权；
- 会话令牌短期有效，可撤销；
- 游戏会话使用单场短期票据；
- 服务间身份使用独立机器身份，不复用玩家令牌；
- 凭据不得写入客户端仓库、日志或配置明文。

## 4. 传输安全

- 后台API强制TLS；
- 游戏UDP传输在会话层进行身份校验、完整性保护和重放防护；
- 每条可靠命令包含序列/窗口；
- 服务器拒绝超窗口、重复和非法顺序命令；
- 敏感后台接口启用双向服务认证或等价机制。

## 5. 命令验证

每条玩家/AI命令至少验证：

- 会话；
- 玩家所有权；
- 实体存在；
- 资源/科技/冷却；
- AI授权区域与预算；
- 可见/可锁定条件；
- 频率/速率限制；
- 序列号；
- 规则集允许性。

任何客户端校验只能改善体验，不能替代服务器校验。

## 6. 战争迷雾防泄露

服务器在序列化前执行情报过滤。安全测试必须证明：

- 未侦察实体ID不出现在普通客户端快照；
- 潜艇/隐身真实位置不泄露；
- 假目标背后的真ID不泄露；
- 未公开生产/科技队列不泄露；
- 观战权限严格区分玩家、队伍、延迟全图和裁判。

## 7. 客户端完整性

排位握手验证：

`game_version, protocol_version, official_content_hash, map_hash, ruleset_hash, allowed_plugin_set`

检测非官方影响模拟的数据时禁止排位。

纯视觉模组必须限定白名单字段，禁止改变碰撞、可见性、界面隐藏信息、动画判定时机和输入自动化。

## 8. 反作弊策略

优先服务器侧规则和行为检测，客户端反作弊只作为第二层。

服务器检测：

- 不可能命令频率；
- 不可能资源支出；
- 未拥有单位命令；
- 未侦察目标精确指令；
- 非法科技/生产；
- 异常命令时序；
- 重复/重放包。

处罚证据必须保存：比赛ID、协议版本、相关命令片段、服务器判定原因和必要日志。

## 9. 限流与滥用

所有公网服务设置：

- 每IP/账号/API令牌速率限制；
- 登录和验证码类接口更严格；
- 匹配票据创建/取消限频；
- 聊天/举报/邀请防刷；
- 结果服务只接受授权游戏服务器来源。

异常峰值可进入保护模式，优先保住已在进行的比赛和结果结算。

## 10. DDoS与服务器隔离

- 游戏服使用短期分配地址/票据；
- 控制面和游戏数据面隔离；
- 单场实例最小权限运行；
- 容器/进程不得持有数据库管理员凭据；
- 云/机房层使用流量清洗、连接限速和区域隔离能力；
- 单实例遭攻击不能扩散到其他比赛。

## 11. 密钥与秘密

- 所有生产秘密进入专用密钥管理系统；
- CI只获得任务所需最小权限短期凭据；
- 禁止把密钥写入Git、构建产物、崩溃日志；
- 定期轮换签名密钥、服务令牌和数据库凭据；
- 泄露事件必须能立即吊销。

## 12. 供应链

- 依赖锁版本；
- 生产构建记录依赖清单；
- 第三方包启用许可证和漏洞扫描；
- 构建产物生成哈希/签名；
- 发布服务器只接受受信任流水线产物；
- AI代理不得自行引入未知二进制插件。

## 13. 隐私最小化

默认只收集完成服务所需数据。

允许：假名化账号ID、比赛结果、性能摘要、崩溃数据、反作弊证据。

默认禁止：与功能无关的联系人、设备文件、麦克风内容、精确位置、无目的长期原始行为轨迹。

崩溃日志必须清洗令牌、路径中的个人信息和聊天内容。

## 14. 数据生命周期

每类数据定义：用途、法律依据/同意、保留时间、访问角色、删除方式。

玩家删除请求必须能处理账号资料和可删除遥测；因安全、财务或竞技完整性依法必须保留的记录应单独标记并最小化。

## 15. 举报与封禁

举报对象：作弊、恶意利用漏洞、骚扰、冒充、违规模组。

封禁等级：警告、短期限制、排位限制、临时封禁、永久封禁。

反作弊自动判定达到高置信度才能自动执行严重处罚；边界案件进入人工复核。

## 16. 安全日志

安全日志至少包含：认证失败、令牌撤销、敏感配置改变、服务器票据异常、内容哈希失败、非法命令、管理员操作、封禁变更。

安全日志与普通性能遥测分离，限制访问并防篡改。

## 17. 发布前安全门禁

- 静态依赖/秘密扫描；
- 内容哈希与签名测试；
- API权限测试；
- 模组沙箱逃逸测试；
- 战争迷雾泄露测试；
- 重放/乱序/伪造命令测试；
- 权限提升测试；
- 服务器镜像最小权限检查；
- 隐私字段审计。

## 18. 事故响应

流程：发现 -> 隔离 -> 停止扩散 -> 保留证据 -> 修复 -> 回归 -> 轮换凭据 -> 必要通知 -> 复盘。

严重漏洞可以立即关闭排位/新会话，但尽量允许进行中的比赛安全结束或保存为 `NO_CONTEST`。
