# 存档、录像、模组与编辑器

## 存档

保存版本、内容哈希、地图、随机种子、模拟状态、玩家/AI 权限、科技、任务状态。战役存档允许迁移；竞技中途存档只用于重连/恢复。

## 录像

记录初始状态 + 命令流 + 周期校验/可选关键帧。录像工具支持跳转、逐 tick、事件搜索、损失/经济/科技统计。

## 模组

模组声明唯一 ID、版本、依赖、目标游戏版本和内容哈希。官方排位只允许官方内容集合；自定义房间在握手阶段交换模组清单并拒绝不一致。

## 编辑器

首发至少支持地图、单位/武器数据、科技树、任务编辑。官方内容尽量使用同一工具和格式，避免“内部编辑器能做、玩家编辑器做不了”的长期分叉。

## 安全

模组默认数据/脚本沙箱，禁止直接任意访问文件系统、进程、网络凭据。脚本 API 采用能力白名单。
