# 安全与反作弊摘要

详细执行规范以 `ONLINE_SECURITY_PRIVACY.md` 为准。本文件只保留游戏侧核心边界。

## 1. 威胁模型

主要风险：修改官方数据、注入非法命令、战争迷雾读取、资源/科技作弊、伪造AI命令、重放/网络篡改、自定义模组冒充官方、账号盗用和服务滥用。

## 2. 权威边界

正式联网采用专用服务器权威模拟。

服务器是单位真实状态、隐藏信息、资源、科技、伤害、AI、机器人、胜负的唯一权威来源。

客户端只发送意图/命令，不提交伤害、资源、位置或胜负结果作为真相。

## 3. 战争迷雾

服务器在序列化前执行情报权限过滤。

未侦察敌军、潜艇、隐身单位、假目标真相、未公开生产/科技等敏感状态不得发送给无权限客户端。

反作弊不依赖客户端“持有完整世界再混淆”。

## 4. 命令验证

服务器对玩家和AI命令统一验证：会话、所有权、资源、科技、冷却、可见性、AI授权范围、战略能力权限、频率和序列。

玩家侧AI不能成为绕过正常资源/科技/权限的特殊入口。

## 5. 内容完整性

排位握手验证：游戏版本、协议版本、官方内容哈希、地图哈希、规则集哈希和允许插件集合。

检测非官方影响模拟的数据时禁止排位。

## 6. 模组

纯视觉模组必须在白名单字段内，不能修改碰撞、可见性、动画判定、隐藏情报或输入自动化。

自定义房影响模拟的模组必须所有参与者内容哈希一致。

## 7. 证据与处罚

严重作弊判定必须绑定比赛ID、版本、命令片段、服务器判定原因和必要日志。边界案件进入人工复核。

## 8. 隐私

遥测最小化；不记录与功能无关个人数据；崩溃/性能日志清洗令牌和敏感字段。数据生命周期、删除和安全日志见 `ONLINE_SECURITY_PRIVACY.md`。
