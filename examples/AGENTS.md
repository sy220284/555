# AGENTS.md — Examples

本文件补充根目录 `AGENTS.md`，适用于 `examples/`。

示例必须证明真实组合可以启动与工作，不能为了让测试通过而绕过 Loader、正式包导出或生产配置。

- **无密钥场景：**通过真实 `cordis.yml` 与 Loader 启动，驱动目标能力，断言输出与干净退出；用于发现默认导出、依赖注入和组合层问题。
- **有密钥场景：**向真实模型发送最小提示，并验证外部可观察状态，不把模型自述当作成功证据；没有 `DEEPSEEK_API_KEY` 时应自跳过。
- 示例依赖优先走工作区正式 package 导出；不要依赖某个包的私有源码路径。
- 快照与夹具是测试资产，更新时必须确认行为变化有意且可解释。

整体架构、测试分层、组合规则与历史故障结论统一见根 `README.md`；仓库级约束见根 `AGENTS.md`。
