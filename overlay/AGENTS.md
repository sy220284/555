# 工作台执行约定

本目录由 ChatGPT 接管的本地“工作台”使用。

## 定位

- DeepSeek Harness 负责本地工作区、会话、文件、终端、插件、技能、索引与执行环境。
- ChatGPT 负责推理、任务拆解、决策、修改、测试、联网研究与最终复核。
- 工作台的本地管理能力不依赖 DeepSeek/OpenAI 等模型密钥。
- Harness 网页可以作为工作台界面和状态入口；若要直接在 Harness 网页聊天框中让 Harness 自主生成回复，仍需要单独配置模型凭据。

## 执行规则

1. 先读取项目自己的 `AGENTS.md`、贡献规范和构建脚本，再修改。
2. 重要变更完成后必须运行对应检查，不以“文件已写入”代替“功能已验证”。
3. 离线永久运行树禁止执行可能重建依赖闭包的 `pnpm install`、`pnpm exec`；优先直接调用已构建入口和现有可执行文件。
4. MCP `localfs` 默认只允许访问 `/mnt/data`，不要扩大权限范围，除非任务明确需要。
5. 工作台默认监听 `127.0.0.1:3080`，不得为图省事直接暴露到公网。
6. 长任务使用 `task-journal` 留下可恢复检查点。
